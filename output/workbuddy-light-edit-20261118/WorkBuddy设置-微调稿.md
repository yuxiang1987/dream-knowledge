## 先看存储路径，别让 C 盘越用越满

这一项先说，因为我自己就在 C 盘空间上折腾过。

我电脑原来只有一块 512 GB 的硬盘，C 盘更是只有可怜的 125 GB。用了 WorkBuddy 一阵子，C 盘动不动就满，搞得我隔几天就得清理一次。

后来，我还赶上硬盘涨价，忍痛加了一块 1TB 的固态硬盘，真是肝疼！

折腾了一段时间后，我才发现，虽然我把 WorkBuddy 装在 D 盘，设置里的「系统缓存目录」却还显示 C 盘。下面这张图是加盘之后截的。

这里先分清两个位置，一个是任务文件存在哪儿，另一个是对话记录和运行缓存放在哪儿。

**打开「设置」，在「通用」里找到「存储」，点「默认工作空间存储路径」旁的「更改」。**
![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261116214902068.png>)
==这个设置管的是以后新建的任务和分组，换个盘只会改变之后的保存位置。旧任务和系统缓存要另外处理。== [官方存储说明](https://www.workbuddy.ai/docs/zh/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/System-Settings#三-存储)

如果 C 盘空间紧张，可以先把默认工作空间选到空间充足的盘。系统缓存要不要迁，先看它实际占了多少。真要动已有数据，先备份哈。

## 自定义指令，把常用要求提前说清楚

我在开始用新的 Agent 工具前，都会先设置一下自定义指令。==说白了，就是把你经常提醒它的话提前写好，之后的对话和任务都会参考，省得每次都重复交代。==

如果你用过 Claude Code、Codex 或 OpenCode，可能见过 CLAUDE.md、AGENTS.md 这样的规则文件。WorkBuddy 则可以直接在设置里填写。

**打开「设置」，选择「个性化」，找到「给 WorkBuddy 的指令」，点击右侧的「编辑」，填入内容后保存。**
![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261116225021232.png>)
下面这份是我常用的指令，大家可以直接使用，也可以根据自己的需求做调整。

```自定义指令
# 行为准则  
减少常见 LLM 编码错误的行为准则。可根据需要与项目特定说明合并使用。  
权衡：这些准则偏向谨慎而非速度。对于琐碎任务，请自行判断。  
  
1. 编码前先思考  
不要假设。不要隐藏困惑。要摆出权衡。  
在实现之前：  
明确陈述你的假设。如果不确定，就提问。  
如果存在多种理解方式，把它们都列出来——不要默默选择一种。  
如果有更简单的方案，就说出来。该反对时就反对。  
如果有不清楚的地方，停下来。指出困惑点。提问。  
  
2. 简单优先  
用最少的代码解决问题。不做任何投机性设计。  
不添加未被要求的功能。  
不为一次性代码做抽象。  
不添加未被要求的“灵活性”或“可配置性”。  
不为不可能发生的场景写错误处理。  
如果你写了 200 行而其实 50 行就够，重写它。  
问自己：“资深工程师会觉得这过度复杂吗？”如果会，就简化。  
  
3. 外科手术式修改  
只动你必须动的地方。只清理你自己造成的混乱。  
编辑现有代码时：  
不要“改进”相邻的代码、注释或格式。  
不要重构没坏的东西。  
匹配现有风格，即使你自己会写得不一样。  
如果发现无关的死代码，提一下——不要删除。  
当你的改动产生孤儿代码时：  
移除因你的改动而变得未使用的导入/变量/函数。  
不要移除预先存在的死代码，除非被要求。  
检验标准：每一行改动都应能直接追溯到用户的需求。  
  
4. 目标驱动执行  
定义成功标准。循环直到验证通过。  
把任务转化为可验证的目标：  
“添加验证” → “为非法输入写测试，然后让它们通过”  
“修复 bug” → “写一个能复现它的测试，然后让它通过”  
“重构 X” → “确保重构前后测试都通过”  
对于多步骤任务，先说明简要计划：  
[步骤] → 验证：[检查项]  
[步骤] → 验证：[检查项]  
[步骤] → 验证：[检查项]  
强的成功标准能让你独立循环推进。弱的标准（“让它能跑”）则需要不断澄清。  
  
如果出现以下情况，说明这些准则正在起作用：diff 中不必要的改动更少、因过度复杂而重写的情况更少、澄清性问题出现在实现之前而不是犯错之后。
```

==这份指令主要给写代码用。我希望它动手前先想清楚，只改相关的地方，少加没必要的功能，改完再检查一遍。==

## 回复风格，选一个你聊着舒服的

和 WorkBuddy 聊天，有时你只想听个结论，它先讲了半天。也有时候，你还没想清楚要做什么，它倒先把答案端上来了。这时候可以看看「回复风格」。

![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261117214549904.png>)

**打开「设置」，在「个性化」里找到「回复风格」。** 我挑三个说说。

- **专业严谨** 像个认真做汇报的同事，讲究条理，解释也比较细。想把一个问题掰开讲清楚，可以选它。
- **高效务实** 主打一个「说重点」。少点铺垫，尽快给结论，适合需求明确、只想赶紧把活干完的时候。
- **启发引导** 适合那种「我有个想法，但一时半会儿说不明白」的情况。可以先让它问几个问题，帮你理理思路。

我平常用得最多的是「高效务实」，回答言简意赅，比较合我的习惯。想讨论方案的时候，也可以换一档试试。这里调的是回复语气，数据和事实还是要看它给的依据。

同一页上面还可以改名字和称呼。我给 WorkBuddy 起名叫「大黄」，让它叫我「boss」。
![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261117215038827.png>)

## 人设设定与长期记忆

这两个入口也在「个性化」。一个写你希望它怎么跟你打交道，一个写你希望它以后还能记得的信息。

### 人设设定

这里可以写 WorkBuddy 的身份、性格和说话方式。比如我希望大黄像熟悉的同事一样跟我说话，遇到有分歧的地方可以直说。

![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261118145732609.png>)

### 长期记忆

比如，你已经在一个对话里介绍过自己是做什么的，换个任务又得从头说。平时经常用到的背景，可以放进「长期记忆」，之后的任务有需要时就能参考。

可以写几条长期有效的信息，比如你的职业、经常做的事，以及已经确认的偏好。「这次先给我英文版」之类的临时要求，放在这次对话里就行。
![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261118145712556.png>)
不知道怎么写，可以把相关信息告诉 WorkBuddy，让它按「人设」和「长期记忆」分别整理成 Markdown。自己看一遍，再贴到对应的输入框。

先写几条常用的就行。用一阵子，发现人设有些别扭，或者记忆里留着过时的信息，再回头改。

## 记忆与进化

我这里的「本地记忆与技能」是开着的。按界面说明，它可以记录值得保留的项目成果和约定，并区分用户级和项目级。经常要接着做同一个项目的话，可以检查这项是否开启。比如「汇总表统一按自然周统计」只给一个项目用，就留在那个项目里。

**打开「设置」，进入「记忆与进化」，找到「本地记忆与技能」。** 

![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261118161213816.png>)

## 窗口设置和模型选择

WorkBuddy 可以在对话框下方切换模型。比如图里的混元 Hy4 flash，截图时标着「限时免费」，活动有时限，使用前看看客户端的说明。 [腾讯混元发布说明](https://www.tencent.com/zh-cn/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows/)
![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261118151235237.png>)
把鼠标放到模型名上，部分模型还会显示「思考强度」和「上下文窗口」。图里的 DeepSeek-V4.1-Flash 选的是「高」和「1M」。

简单任务用默认设置就行。遇到需要多想几步的问题，可以考虑提高思考强度，最后还是要检查结果。上下文窗口看的是这次要带多少资料和对话内容，比如要同时读几份长报告，默认容量不够、模型也支持，再考虑调大。
![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261118151348857.png>)
在「设置 → 智能体」里可以找到「经济模式」。开启后，WorkBuddy 会适时压缩上下文，减少长对话中重复传输的内容。 [官方模型说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model)

做大项目时，我更建议分阶段留一份台账，记下已经确认的决定、做到哪一步、下一步要读哪个文件。新开对话就让它先读台账和当前用得上的资料，接着做。不同阶段也可以按任务换模型，或调整思考强度。

## 数据导入

如果你之前用过别的 AI 工具，可以到「设置 → 数据导入 → 导入其他应用数据」看看有什么能带过来。我这边的列表里有 ChatGPT、Cursor、Claude Code 和 Claude Cowork。展开应用后，按当前能选的项目导入。比如图里的 ChatGPT 检测到了几类内容，Cursor 则显示 0 项。想接着做旧任务，可以先单独导入任务，打开确认资料齐不齐。

![](<../../raw/article/程序员梦哥/assets/WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你/file-20261118152041770.png>)

## 写在最后

要是那位家长再问我从哪一项开始，我会先推荐自定义指令。把你最常提醒 AI 的那句话先填进去，再拿手边的活试一下。觉得它答得太啰嗦，就调回复风格。每次换个对话都要重新介绍自己，就补几条长期记忆。

七项不用一次改完。下回遇到具体的麻烦，能想起来去哪儿调一下，这篇就没白看。
