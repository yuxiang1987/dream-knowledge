# 程序员梦哥 · 《GPT Image 2.6 手搓鲁班皮肤》纯 SVG+SMIL 定制片头 v1

面向知识库内归档文章 `raw/article/程序员梦哥/GPT Image 叒叒叒更新了，我用它手搓了一套鲁班皮肤.md`（关联主题 `[[topics/GPTImage鲁班创作与攻击动图案例]]`）定制的公众号文章开头动画。

## 技术方案（对齐「摸鱼小李」纯内嵌 SVG + SMIL 架构）

参考 `[[topics/摸鱼小李文章片头动画实现]]` 的源码核查结论，本片头采用 **100% 纯矢量内嵌 SVG + SMIL 声明式动画**（`intro.svg` 约 170.6 KB），同时配套输出同时间轴的 **GIF 兜底版**（`intro.gif` 约 712.2 KB）：

- **统一首屏横幅画布**：`viewBox="0 0 1246 220"`，周期 `8s`，`repeatCount="indefinite"`。
- **零外部依赖、零位图、零字体缺失风险**：
  - 零 `<text>` 标签：所有中英文标题、口号、步骤胶囊与卡片文案均由 `@napi-rs/canvas` 的 `convertSVGTextToPath` 转为独立 `<path>` 字形路径。
  - 零 `<image>` 标签：左侧常驻「像素梦哥」由既有 `sprite-idle.png` 量化合并为纯矢量 `<path>` 像素块（分上身呼吸层与下身站立层，带 `2.4s / 3.2s` 异步呼吸与眼镜高光闪烁）。
  - 零 `<script>` 与外部 URL：纯 `<animate>`（78 个）与 `<animateTransform>`（67 个，其中 66 个带 `calcMode="spline"` 贝塞尔缓动曲线）。
