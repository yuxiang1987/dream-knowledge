## 动作

1. 人物向右走，发射第一枚炮弹，击中紫色怪物。
2. 跳起顶第一块砖，解锁`dream`。
3. 向右移动，跳起顶第二块砖，解锁`coder`。
4. 发射第二枚炮弹，击中红色怪物，再跑向旗杆。
5. 旗帜从高处沿旗杆降下，人物停留；两词和主文案共同展示。
6. 动作层淡出、复位后淡入；主文案与环境保持可见，首尾画面相同。

## 文件

- `intro.gif`：1200×360、25fps、250帧、10秒、无限循环。
- `preview.html`：重播、下载、375px文章预览和十个关键帧。
- `poster.png`、`mobile.png`：过关停留画面与手机尺寸定帧；`keyframes.png`：动作对照。
- `build.cjs`、`manifest.json`：源码、时间线和验证状态。
- 三张`sprite-*.png`：既有角色原文件的复制。

主体由Canvas绘制、FFmpeg编码；既有idle/run/jump角色复用，怪物、炮弹、砖块和旗杆为代码图形。未新调用生图或Image 2.6，未交付SVG。人物与两块砖的接触、炮弹命中、两词解锁顺序、降旗方向及循环接缝由测试检查；本地另查看关键帧和手机定帧。审美待用户反馈，公众号后台保存重载与真机效果未验收，未修改Skill或发布。

重建：需Node.js、FFmpeg、微软雅黑及既有`../程序员拾梦闯关片头五案-v1/node_modules/@napi-rs/canvas`，执行`node build.cjs`。中间帧`_frames/`忽略。测试：仓库根目录运行`python -m unittest discover -s scripts -p test_mengge_pixel_level.py`。
