# 写作与定稿正文2500字门槛

2026-11-13按用户要求，wechat-article-writing和gzh-final-check均加入完整文章正文至少2500字（含2500字）的检查，两个技能各自附带相同的只读scripts/check_article_length.py，互不依赖安装。

字数口径：正文汉字、字母、数字各计1字，去除空白、标点、各级标题、元数据、Markdown标记、图片替代文字与路径、链接目标、代码/提示词、引用块、参考资料及固定个人简介。保留链接可见正文。无明确边界的提示词、标题和文外说明需在临时统计副本中先标清，原稿不变；不承诺与微信后台统计数字相同。
