# Fusion Pixel 字体来源

- 项目：https://github.com/TakWolf/fusion-pixel-font
- 发布版本：2026.11.10
- 使用文件：`fusion-pixel-12px-proportional-zh_hans.ttf.woff2`，完整原文件，未子集化或修改。
- 发布包与SHA256见`source.json`。
- 主授权文件：`OFL.txt`（SIL Open Font License 1.1）；发布包附带的上游授权完整保存在`LICENSES/`。

仅在本项目渲染进程中注册，没有安装或修改系统字体。按12px原始字形栅格化、阈值去除半透明边缘，再用最近邻整数倍放大。主题为5倍，中文片尾为6倍。PNG与GIF已包含最终字形，阅读成片不依赖设备字体。
