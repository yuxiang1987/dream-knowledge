## 这版的具体变化

- 内置image_gen参考既有蓝卫衣角色生成透明4×4动作表：8个跑步姿势、4个举炮/瞄准/后坐/恢复姿势、4个蹲下/上升/下落/压缩落地姿势。16格均接入动画，不再依赖旧版的腿部翻转。
- 采用统一像素缩放比例和逐格脚底锚点，不把矮身姿势强行拉到同一高度。发炮接入实际炮筒姿势、轻微后坐和炮口闪光；跳跃接入蓄力与压缩落地，另有少量落地尘点。
- 调整两次顶砖的接触位置与炮弹高度；小怪同步放大。旗杆向左移动，角色从x=120走至960。
- 主题优先：0.8秒顶第一块砖弹出GPT，2.4秒顶第二块弹出Image 2.6，文字各用0.48秒上弹、轻轻回落，2.88秒完整停稳。文字不翻转、不消失，保持可读到降旗；砖被顶后留空。源码顶部`TOPIC`数组是本期主题的修改位置。
- 两次发炮打怪安排在主题出现之后。降旗6.2秒完成，6.24—6.66秒主题与两砖退场；6.72—7.32秒「折腾AI、少踩坑」轻微上移并渐显，7.32—9.32秒完整静止两秒，再淡出复位。

## 文件与复现

- `intro.gif`：1200×360、25fps、260帧、10.4秒、无限循环。
- `preview.html`：重播、下载、375px文章预览及关键帧。
- `poster.png`、`mobile.png`、`keyframes.png`：停留定帧、手机定帧和十个动作时刻。
- `topic.png`、`mobile-topic.png`：完整主题定帧与375px主题可读性预览。
- `action-sheet.png`：真实内置image_gen生成的透明动作表，已复制至本工作区。
- `imagegen-prompt.txt`：生成工具、参考图角色与完整实际提示词。
- `build.cjs`、`manifest.json`：重建源码、透明格裁切范围、角色缩放比例与时间线。

动作表使用内置image_gen生成，工具未返回可核验模型型号，不声称Image 2.6。GIF由Canvas场景与FFmpeg编码完成；没有生成原生GIF或交付SVG。自动检查与关键帧审阅不等于审美或平台验收，用户观感与公众号后台保存重载、真机效果仍待确认。未改Skill、未设为默认片头、未发布。
