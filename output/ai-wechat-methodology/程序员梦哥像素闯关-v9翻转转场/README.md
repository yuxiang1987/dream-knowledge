## 翻转方式

- 降旗5.44秒完成；5.46秒起，七图标与三砖作为十张独立平面绕竖轴由0度转至90度，收为侧边后消失。每张0.52秒，图标以0.025秒错峰，最后一张6.13秒完成。
- 使用逐列透视投影，近侧和远侧高度随深度变化，不是单纯缩放宽度。整数目标列避免列缝；正面终点直接绘制原图，保留像素硬边。卡片背面不显示。
- 6.04秒「分享AI、少踩坑」从-90度侧面翻入到0度正面，同时轻微上移；6.56秒完全停稳，6.56—8.56秒静止两秒，再淡出复位。不出现镜像文字。
- 保持1200×360、50fps、450帧、9秒、每帧20ms、无限循环。GIF为1713426字节；编码帧率不保证所有微信客户端实际以同样帧率播放。

## 文件与复现

intro.gif为新版；preview.html含375px预览、v8粒子版对照与翻转关键帧。transition.png为翻转中段；title-face.png为正面口号透明图层；topic.png、mobile-topic.png为散开定帧，poster.png、mobile.png为口号停留定帧，keyframes.png重点展示5.44—6.6秒。

flip.cjs提供时间角度、透视投影和逐列渲染；motion.cjs用GSAP控制原动作、口号翻转与复位；build.cjs提取三砖与口号图层并渲染卡片。七图标继续由v7原绘代码生成，没有截图输入或新增生图。manifest.json保存转轴、角度、张数、错峰、透视距离、时间线与每帧状态。

执行node build.cjs重建。依赖沿用v6的GSAP 3.15.1、五案v1的Canvas、v3动作表和Fusion Pixel字体、v7图标代码及FFmpeg。中间帧_frames忽略。

根目录运行python -m unittest discover -s scripts -p test_mengge_pixel_flip.py。本版4项、相关共35项通过：前段定帧/原绘图标/最终口号与v8逐字节相同、真实透视近远侧差异、0度原图精确呈现和±90度隐藏、角度单调及不镜像、显隐顺序、随机顺序seek、实际翻转编码帧、50fps/9秒/首尾闭合和片尾两秒静止。
