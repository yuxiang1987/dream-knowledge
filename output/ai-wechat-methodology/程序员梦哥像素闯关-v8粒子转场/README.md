# 程序员梦哥 · 像素闯关 v8 粒子转场

2026-11-13按用户反馈，仅优化降旗后的图标/砖块退场和文字出现。沿用已认可的左侧走入、单次顶中砖、七枚原绘图标散开、无战斗、走向旗杆和「分享AI、少踩坑」。v7保留对照。

## 转场

- 降旗5.44秒完成；5.46—6.16秒，图标与三砖按8×8像素格逐步松散，细小碎片轻轻飘移、缩小和淡去。碎片来自本场景透明内容图层的原色与形状，包含960个有效格，不是另加一团通用彩纸。
- 格子启动延时受固定坐标种子控制，轻微从左向右错开；每片在0.46秒内退场，水平漂移不超过46px、向下不超过38px，不影响人物、旗杆、地面、天空和背景。
- 6.04秒口号开始渐显并上移，和最后少量粒子重叠0.12秒；6.56秒完全停稳，保持两秒，8.56秒开始淡出复位。
- 总时长从8.8秒微调到9秒，1200×360、50fps、450帧、每帧20ms、1948290字节，无限循环。编码帧率不代表微信客户端实际播放帧率承诺。

## 文件与复现

intro.gif为新版；preview.html包含重播、375px预览、v7对照和转场关键帧。transition.png是消散中段；particle-source.png是仅含图标和三砖的透明粒子源图层，可检查人物/旗杆未参与拆分。topic.png和mobile-topic.png保留散开定帧，poster.png与mobile.png为片尾，keyframes.png突出5.44—6.24秒的退场过程。

particles.cjs用固定网格、坐标散列和无状态取样函数计算每片位移/大小/透明度；motion.cjs继续用GSAP组织其他动作、退场开关、口号和复位；build.cjs捕获原绘内容图层、实际渲染粒子并导出。manifest.json包含种子方式、格子数量、过渡时间及逐帧状态。粒子重组的首帧与原图层逐像素一致，避免整块切换时跳变。仍然只使用v7的原绘图标代码，没有截图输入或新增生图。

执行node build.cjs重建。依赖沿用：v6的GSAP 3.15.1（在v6目录npm ci --ignore-scripts恢复）、五案v1的Canvas、v3动作表和Fusion Pixel字体、v7原绘图标模块、FFmpeg。中间帧_frames忽略。

根目录运行python -m unittest discover -s scripts -p test_mengge_pixel_dissolve.py；本版4项、相关历史版本合计31项通过。检查包括认可的散开定帧和图标字节不变、原透明图层精确拆分/重构、固定种子确定性、碎片按时消失、图层不含人物旗杆、降旗后转场及文字重叠窗口、随机顺序seek、实际粒子编码帧、9秒50fps、首尾接缝和片尾两秒静止。
