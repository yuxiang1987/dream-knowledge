# 右侧动效三款

用户要求右边动画多生成几种，本轮制作三种独立候选。头像、文案、色调、画幅与6秒循环沿用v1，原方块版的成品不覆盖。

- A `code-window`：代码窗口，代码行逐行刷出，光标闪动。
- B `file-flow`：文件夹与数据流，像素文件在两个文件夹之间移动。
- C `spark-orbit`：像素火花汇聚，粒子环绕并聚成四芒火花。

打开 `preview.html` 并排比较；每款交付GIF、独立SVG、文字首帧和动效定帧。GIF均为1246×220、20fps、120帧，约1.5至1.6MB。粒子与轨迹固定，重复播放可复现；“几种”指三款候选，没有给公众号添加运行时随机脚本。

生成源码为上一级的 `build-variants.cjs`，与v1共用头像、像素文字及转场。它只新增本目录成品，不覆盖v1的GIF或SVG。设置好 `@napi-rs/canvas` 包搜索路径后执行 `node build-variants.cjs`，需要ffmpeg。

已检查本地定帧、GIF循环与SVG结构；尚未在公众号后台保存或真机微信预览中验证。
