# 把想法折成小程序 · 创意片头样片

文章：`raw/article/程序员梦哥/WorkBuddy + huashu skill 手搓健身小程序（附提示词）.md`。

本版采用「折纸手机」隐喻：需求纸展开成三套原型，选中正文中的青柠色方案 C，纸张侧翼与顶角依次折合为手机。手指按下开始运动后，能量环增长，跑步角色随之出现。左侧沿用程序员梦哥品牌人物与点阵口号，8 秒循环。

## 看样片

- `intro.gif`：1246×220、160 帧、8 秒循环；从 SVG 在浏览器里的实际动画属性逐帧导出，便于直接预览。
- `preview.html`：原生 SVG 动画预览、从头播放、六个时间点定格，以及复制公众号富文本片头。
- `intro.svg` / `intro.wechat.html`：矢量源文件和内嵌片段。
- `frame-*.png`：六个关键帧。
- `storyboard.json`：创意和时序记录。

## 分镜

| 时间 | 画面与因果 |
| --- | --- |
| 0–1.92 秒 | 品牌人物待机，点阵口号坍缩成粒子 |
| 1.8–2.76 秒 | 需求纸写出“我想做个健身小程序” |
| 2.44–4.1 秒 | 纸张展开为红黑网格、自然绿留白、炭黑青柠三套原型，指针选中 C |
| 3.88–5.03 秒 | 选中页移向中央，图纸侧翼与顶角折合，圆角、边框和屏幕成为手机 |
| 5.03–5.6 秒 | 手指靠近，按钮受压并回弹 |
| 5.62–7.04 秒 | 点击触发能量环增长，跑步角色出现，收尾对勾 |
| 7.04–8 秒 | 舞台淡出，口号复位，衔接下一轮 |

纸张折合是创意表达；手机界面及跑步角色为示意，没有使用虚构运动成绩、价格或正式上线结论。
