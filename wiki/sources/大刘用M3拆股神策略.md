## 主问题

MiniMax M3 金融 Agent 能否把零散群聊文档与截图中的“股神经验”还原成可计算策略并完成回测，同时在网页可视化和 Three.js 代码生成中与其他模型竞争？

## 目标读者

适合关注 AI 金融研究、文档解析、量化验证和前端生成能力的普通投资者、研究人员与开发者。对没有量化基础的读者，文章提供了从经验到可验证策略的直观路径；但其中任何回测结果都不应直接转化为交易决策，专业投资者需要补做数据与方法审计。

## 主研究对象

主要测评对象是 MiniMax M3 Agent 网页端的金融模块、多模态文档处理、金融数据库连接、长上下文与 Coding 能力；对照对象包括 DeepSeek V4 Pro、Kimi 2.7、GLM 5.2，以及 3D 场景任务中的 Claude Opus 4.7。素材对象是姨妈提供的五份群聊策略文档和一张截图。

## 证据身份与分项边界

策略提取部分属于作者亲测报告：作者上传五份文档和一张截图，报告 M3 思考17次、查看9个文件、执行20条命令，并调用 LibreOffice 转换 .doc、执行 OCR，最后还原出作者概括为“突破、抢筹、极”的三路共振策略。回测同样是作者亲测叙述，作者称使用全 A 股一千多只股票、2024年6月至2026年6月两年数据，耗时20分钟，得到窄窗口内胜率约50%、平均3%多正收益、盈亏比约1.4的结果；但原始公式、样本清单、交易成本、持有期、止损规则、代码和完整报告均未提供。51.9分及对手44.4、37.0、33.3属于作者转述的官方金融研究评测，不是本文独立复测。网页横评属于作者亲测和主观评价：输入同一策略材料，比较四个模型的页面成品，作者认为 M3 更符合手机卡片和高级审美，但正文媒体未看，且没有量化评分。Three.js 场景属于作者亲测：给 M3 与 Opus 4.7 相同提示词，作者认为效果基本打平，M3有塑料高光、警示灯转动、皮卡抖动和风滚草细节，同时承认 M3 更慢；没有给运行时间、代码正确率、帧率或价格数据。“1M上下文”“完全开源”“价格便宜一大截”等为作者陈述，本文未独立核实。

## 标题承诺与开头

标题用“蹲了十年的股神秘籍”“全挖出来了”制造秘闻、稀缺性与强结果预期。正文确实讲述了从五份零散文档和截图中提取三路策略并回测的过程，基本兑现“挖出策略”；但没有公开完整秘籍、公式和报告，读者无法复现，“全挖出来”是作者结论而非可核查交付。开头不先讲模型参数，而从姨妈转发消息、十年股神群和主动用 AI 炒股切入，以家庭关系和“韭菜”身份降低金融技术门槛；随后用过去模型处理不了截图与新金融 Agent 可能有戏的反差，把读者带入实验。

## 结构与转场

第一段以姨妈和股神群建立故事场景，接着交代输入材料混乱及旧模型边界，再引出 M3 金融 Agent。第一阶段是文档解析：上传材料、展示 Agent 的文件转换与 OCR 行为、总结三路共振逻辑，并插入官方评测为能力背书。第二阶段自然转入“逻辑挖出来，得验证”，通过金融数据库完成全市场回测，得出策略仅在窄窗口有效的降温结论，并借此讨论幸存者偏差。第三阶段以“本来该收工”转入扩展横评，先做四模型手机网页对比，再做 M3 与 Opus 4.7 的 Three.js 场景对比。最后由具体任务上升到长上下文、多模态、Coding 和开源价值，加入投资风险声明后结束。整体叙事有发现—验证—降温—扩展测试—价值升华的推进，但金融主案例与网页、3D 两个附加案例的评价口径不统一。

## 案例：目标、输入、操作、结果与人工成本

案例1为股神策略逆向：真实目标是把姨妈所在群聊中长期零散传播的选股经验还原为可计算逻辑；输入是5份文档和1张截图，其中含大白话、实盘截图及 .doc 文件；操作是一次性上传至 M3 金融 Agent，作者观察到其思考17次、查看9个文件、执行20条命令、调用 LibreOffice 转换文档并做 OCR；结果是提炼出“突破、抢筹、极”三路共振体系和报告。作者没有公开原始材料、完整公式、OCR错误、人工纠错内容或总费用；除盯着过程和将结果概括成三路外，也未说明自己是否修订了公式。案例2为策略回测：目标是验证提取逻辑是否真如群内宣传般准确；输入是提取后的规则、全 A 股一千多只股票及作者所称2024年6月至2026年6月数据；操作是让金融 Agent 连接数据库跑两年全市场数据，耗时20分钟；作者报告结果为仅在评分刚冒头且未过热的窄窗口有效，每天选综合得分最高的少数股票时胜率约50%、平均正收益3%多、盈亏比约1.4，并判断只是“及格策略”。未给持有周期、样本精确数量、基准指数、手续费、滑点、复权、停牌与涨跌停处理、样本外验证、显著性、最大回撤及人工修正，且时间区间终点与文章环境需核实。案例3为策略报告网页横评：目标是把公式、表格和回测数据改造成姨妈能在手机阅读的卡片式网页；输入是同一份策略报告和一句“手机直接点开、卡片式、审美高级”的要求；操作是分别交给 M3、DeepSeek V4 Pro、Kimi 2.7、GLM 5.2；结果是作者认为 DeepSeek 信息最足，Kimi 与 GLM 规整但偏报告搬运，M3 的留白、配色和逐屏层次最符合其预期，且 M3 一次完成、未返工。该结果是作者主观亲测，未给统一评分表、生成耗时、代码错误、模型参数和各自成本，媒体成品本文未核看。案例4为 Three.js 3D 对比：目标是生成 Mad Max 风格 LEGO 沙漠前哨站；输入是正文公开的完整提示词，包含材质、色彩、加油站、广告牌、皮卡、货物和仙人掌等要求；操作是让 M3 与 Claude Opus 4.7 各自生成 Three.js 场景；结果按作者观察，M3 实现塑料高光、旋转警示灯、皮卡抖动和风滚草，与 Opus基本打平，但运行更慢、价格据称更低。未给耗时秒数、token、费用、浏览器兼容性、代码修改次数和客观完成度清单。案例5为官方金融评测：目标是比较金融研究能力；输入和评测流程由官方基准决定，正文未提供；结果是作者转述 M3 51.9、V4 Pro 44.4、Kimi 37.0、GLM 33.3。该项是官方主张而非作者独立复现。

## 解释、语言与图文作用

文章用家庭故事包装技术测评，把 OCR、回测、Three.js 等术语立即翻成白话，例如将回测解释为“用过去的真实数据去跑”。策略则拆成“突破、抢筹、极”三个容易记忆的标签，先给直觉再略述含义。节奏上频繁使用短句和转折：“我觉得可能有戏，说干就干”“有用。但远没有传说里那么神”，形成先抬高期待、再以回测降温的戏剧性。评价网页和3D时大量使用视觉感受与细节列举，阅读生动，但“准的离谱”“最稳”“能稳稳小赚”“效果不输”等词的证据强度不一致。开源段转为情绪化评论，用训练成本想象和“英雄主义”强化品牌形象。

## 结尾收束

结尾从具体性能转向国产模型进步与开源价值，先强调模型同时具备长上下文、Coding、多模态，再将“完全开源”描述为放弃锁定核心能力的英雄主义，并与海外模型的能力和封锁形成对照。随后承认超越需要时间，以“始终在路上”收束情绪。最后加入“市场有风险，投资需谨慎”和不构成投资建议的声明，再进入点赞、星标及作者介绍。风险提示存在，但位置较晚，且不能替代对回测方法的详细披露。

## 限制与不可照搬处

金融策略最关键的公式、报告和代码没有公开，无法复现提取与回测。回测缺少基准、持有周期、调仓频率、手续费、滑点、复权、幸存者偏差处理、未来函数检查、样本内外拆分、最大回撤和统计显著性；“胜率50%上下、平均3%多正收益、盈亏比一块四”也未说明统计口径。作者称区间为2024年6月至2026年6月，具体数据是否完整、是否包含未来或模拟数据需要核实。把约50%胜率和未完整披露的收益指标概括为“稳稳小赚”证据不足。官方评测分数的基准名称、版本和同条件设置未提供。网页审美只有作者单人判断，正文媒体未看；3D测试未计时、计费或检查代码质量，因此“基本打平”“便宜一大截”不能独立确认。模型版本、1M上下文、开源范围、许可证、金融数据库覆盖和价格均未独立核实。没有披露 M3 对原始策略识别失败或人工修正的记录，也未讨论把私人群聊和截图上传第三方服务的隐私与合规问题。

## 可迁移的编辑动作

编辑 AI 金融实测时，应把“策略提取”和“策略有效性”严格分开：先展示至少一段脱敏原文、OCR文本、模型提取公式及人工校验，再给完整回测假设。结果表必须包含样本数、选股日、持有期、交易成本、基准、年化收益、最大回撤、胜率、盈亏比和样本外表现，并明确所有数字是作者报告。横评应固定模型版本、提示词、运行次数、预算和评分维度；审美可邀请多名目标读者盲评，代码任务则检查功能完成度、报错、性能与人工修复。若主线是金融研究，网页和3D案例可压缩成能力外延附录，避免稀释核心证据。该框架适用于有合法数据来源、能审计公式且仅用于研究的场景，不适合把未知群聊策略直接自动交易。

## 自己的待测方向（待实操，非已执行）

面向会看财报但不会写量化代码的个人研究者，我会使用一份公开可引用的中文研报和其中两张指标截图作为自己的输入，要求 M3 提取明确的选股条件并生成可执行伪代码。第一步先人工制作一份标准答案，包括OCR文本、变量定义与公式，再上传同样材料给 Agent。观察点包括 OCR 字符错误、公式参数遗漏、单位与时间窗口误读、数据源调用是否可追溯、生成代码能否运行，以及模型是否主动提示不能确定的信息。之后用固定的公开股票池划分样本内和样本外区间，加入手续费与滑点，并与简单指数基准比较。所需证据为原始材料、标准答案、Agent日志、数据来源、代码仓库、错误与人工修正表、完整回测指标和重复运行结果；不进行实盘下单，也不以单次收益作为有效性结论。
