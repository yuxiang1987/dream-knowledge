# 豆包爱学诗词山河文章拆解

来源：`raw/article/lurenjiaTM/豆包爱学这次，做了个有点浪漫的东西.md`，署名时间 2026-08-20。视频与截图未在本页核看；产品能力、视频质量与课标覆盖数量均为原文自述，未独立核实。本篇未发现购买引导或促销内容，但通篇以正面介绍为主，拆解时不把它当作学习效果验证。

## 定位、标题与开头

这是**教育产品体验＋产品价值判断**。读者问题不是「这个功能怎么用」，而是「AI 教育产品到底有没有改变学习方式」。作者明确说明自己不是教育产品的典型用户——没有作业要辅导、没有古诗要陪背——这个自白反而提高了可信度，因为他没有假装成目标用户。

标题「豆包爱学这次，做了个有点浪漫的东西」由**产品名＋留白式评价**组成。这是本库中**信息留白**最典型的样本：不说功能、不说收益，只用「有点浪漫」勾好奇，让读者带着「什么东西」的疑问点进来。正文确实回应了这份好奇（把古诗放回真实地点、把零散知识连起来）。留白型标题的成立条件是正文要有对应内容的解释，而不是拖到最后才说；这一点本篇兑现了。

开头先给一个所有人都能答对的设问「白日依山尽，下一句是什么」，紧接着说正因为太容易，自己一直怀疑「AI+教育」——当答案变得零成本，学习到底被改变了，还是只是被加速了。随后提出判断标准：如果只是把老师、题库和教辅装进一个更聪明的聊天框，学习方式并没有真正变化；学习还包括把零散知识串起来、发现自己哪里没懂、愿意继续探索。最后引出体验对象。

钩子类型是**常识设问＋自我怀疑＋先立判断标准＋非典型用户自白**。先立标准再介绍产品，后面的评价才有依据；否则「有点浪漫」这类评价会显得随意。

## 结构与推进

三部分与开头提出的学习要素基本对应：

1. **把古诗放回真实发生的地方**：打开产品先见古代疆域地图而非课程目录，诗词按地点分类（有古迹的放在古迹剪影旁，没有的归入创作城市）；可在唐代、北宋、南宋之间切换，疆域、城市标注、诗词分布与视觉风格随之变化。作者用《登鹳雀楼》解释缺失的那层信息是「坐标」——鹳雀楼在哪里、王之涣为什么要登这座楼、他为何产生这样的视野。
2. **把抽象知识变得可感知**：卷轴含译文、创作背景与重点字词，配 TTS 朗读；部分作品有 AI 视频；给出王昌龄与王安石两段诗人故事视频，作者评价画面细节真实、叙事清楚，并以边疆画面传达荒凉与残酷为例。随后是讲解课程与完整链路：发现一首诗 → 理解它发生在哪里 → 认识作者和创作背景 → 进入更深的课程。
3. **把分散的知识重新连接起来**：从城市进入可看到同一地点的多首诗；从诗人进入可沿李白、杜甫、苏轼的足迹看他们在不同人生阶段写下什么，并解释「为什么李白的诗里总有山河与远方」。作者点出这背后是三层对应：古今地名对应帮助地理，疆域与朝代变化帮助历史，诗人经历回到语文。产品覆盖课标内 200 多首并可按小学、初中、高中筛选，把探索与正式学习任务衔接起来。

结构上最值得学的是**开头的标准与正文三部分一一对应**：串联零散知识对应地图与地点分类，发现自己没懂对应可听可看的呈现，愿意继续探索对应跨城市与跨诗人的连接。这让「有点浪漫」落到具体设计上。

## 可复用的观察角度

| 观察 | 原文做法 | 可迁移的写法或测试 |
| --- | --- | --- |
| 从缺失的一层信息切入 | 背诗会记得作者与名句，却未必想过地点、登楼原因与心境，作者把这一层概括为「坐标」 | 评价学习类产品时先问「它补上了传统方式缺失的哪一层」，比罗列功能更能说明设计价值 |
| 用对照讲设计变化 | 打开产品先看到地图而不是课程目录；从城市看同地多诗，从诗人看迁徙轨迹 | 用「原来的做法是什么／它改成了什么」的对照解释设计，而不是只描述界面 |
| 坦诚自己的用户位置 | 明确说自己没有作业要辅导、没有古诗要陪背 | 非目标用户的体验文章要先说明距离，再把观察限定在设计与内容呈现上 |
| 主动给出待验证问题 | 结尾提出「看得有趣是否等于真正学会」「AI 生成的意境画面会不会限制想象空间」「能否转化为记忆、表达与知识迁移」 | 体验类文章的收尾可以列出自己无法验证的问题，这比替产品下效果结论更可信 |

## 证据与边界

「第一次在市面上看到将古诗词和古代地图结合的产品」是作者的个人观察，不能当作市场首创的事实。「覆盖课标内 200 多首」出自产品说明，未核对课标范围。视频质量评价（人物细节真实、叙事清楚）来自作者观看，本页未核看视频，不能复用为画面结论。

更重要的是作者自己划出的边界：全文没有提供学习效果证据——没有测试学生对诗词的记忆、表达或知识迁移，也没有对照组。因此本篇能支持「产品设计有具体想法、内容组织方式与常见教育产品不同」这类判断，不能支持「能提高学习成绩」或「比传统方式更有效」。结尾三问正是对这一缺口的自觉说明。

## 结尾与写作卡片

结尾把价值判断收在「从提供工具走向搭建环境」：原本孤立的文字在城市、朝代、诗人经历与真实地理的交织下重新连接，先让学生产生兴趣，再借助朗读、意象视频与课程逐渐深入。随后主动列出三个尚不能回答的问题，没有替产品下效果结论。

**写作卡片**：适合非典型用户的产品体验 → 先用一个人人会的设问建立怀疑 → 给出自己的判断标准 → 说明自己与目标用户的距离 → 用「原来的做法／产品改成了什么」的对照讲设计 → 让各段落对应开头的标准 → 结尾给出一个价值判断并列出无法验证的问题。
