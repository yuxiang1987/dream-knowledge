# 卡兹克十二个Prompt文章拆解

来源：`raw/article/kazike/都Agent时代了，我还是想分享给你这12个我最常用的Prompt。.md`，原文署名时间 2026-08-21 08:08。本文仅蒸馏文字；图片未核看，模板未独立运行。

## 它讲什么

主问题：进入 Agent 时代后，普通人还可以怎样用提示词改善提问、学习与判断？文章不是追新工具，而是回应读者要求，把过去散落的模板重新删改归类。

## 关键要点

- 全文按五种需求组织十二个模板：问清问题一项（苏格拉底式提问）；学习四项（双层解释、反向拆解、横纵分析、事实核查）；解决问题三项（专家会诊、第一性原理、跨领域借解）；决策两项（双向钢人论证、最小实验）；认识自己两项（天赋挖掘、人生设计）。
- 苏格拉底模板限定最多六问、一次一问，只追问可能改变结论的信息；确认新问题后才给建议。钢人论证则针对已有选项，分别构造最有力的支持理由，避免把两种用途混淆。
- 双层解释要求生活类比与专业机制对应；横纵分析把历史演化和同维竞品比较合并，并要求一手来源、日期、事实与推断分离、冲突并列。
- 专家会诊的重点不是给模型戴资历帽子，而是让互补视角相互质疑；跨领域迁移须写明相似结构及失效条件；最小实验要求指标、继续与停止条件。
- 两个自我探索模板都用具体经历作判断依据，以低成本行动检验，而非直接给人生定论。结尾承认受众层级差异，回到“知道自己要什么”的人的主体性。

## 写法与可复用方法

标题用“都……了，我还是……”制造逆潮流张力，再以“12个”“最常用”给范围和个人筛选承诺。开头交代读者反馈与重新整理动作，降低炒冷饭感；正文先列真实困惑，再配完整可替换模板，比单列方法名更便于使用。

可复用结构：**用户要解决的事 → 选哪种方法 → 为什么不是相邻方法 → 可复制输入与输出规格 → 验证或停止条件**。合集应按读者任务分类，不按工具名堆砌。结尾把使用技巧提升为提问和判断能力，而不是继续增加模板。

## 证据边界与疑问

“适配所有AI”“一定越有用”等是作者判断，未提供跨模型测试。天赋、心理学和人生设计模板不是经验证的心理评估，也不能替代专业咨询；长篇输出不等于结论准确。本文收录模板的结构价值，不承诺实际效果。
