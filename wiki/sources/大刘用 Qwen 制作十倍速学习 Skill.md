## 主问题

如何把一篇“十步学习法”文章转成可反复调用的 Skill，并借 Qwen3.8-Max-Preview 在 Claude Code 中生成围绕指定主题的交互式学习 HTML；该模型能否继续承担 3D 页面和超长文档等长程任务？

## 目标读者

适合能够安装或调用 Claude Code、接入第三方模型、管理项目文件并愿意与模型多轮澄清需求的开发者、研究者和知识型创作者。只想输入一个词立即得到可靠课程的纯新手，需要额外关注信息来源、前置水平、测验质量和事实核查；文章本身并未提供安装步骤、依赖、权限设置或常见报错，因此不是完整的新手安装教程。

## 主研究对象

主要面向使用 Claude Code、理解 Skill 概念、希望把个人方法论产品化的 AI 进阶用户，同时向想低成本执行长程任务的人推荐 Qwen3.8-Max-Preview。开源 Skill 可服务任意学习主题的说法面向广泛学习者，但实际只明确展示“RAG”主题；3D 和外贸 SaaS 文档是另外两类作者任务，不能共同证明所有领域都适用。

## 证据身份与分项边界

作者亲测主案例是把上一篇十步学习法全文放入项目，以整体需求、功能需求和产出需求提示 Qwen，再调用 grill-me skill 多轮澄清，生成 Skill 文件，最后仅输入“RAG”产出十步交互式学习 HTML。作者报告单次生成超过30分钟，包含论文原文参考，结果在完整度、推理深度和审美上良好。另两个亲测描述分别是生成 Three.js 3D 街道场景，以及整合20多个文档、产出8万字180页 Word 设计文档；但均未展示完整输入、文件、运行日志、错误或人工修订。2.4万亿参数、正式版将发布并开源、活动折扣和 Token Plan 规则属于文中官方或传闻口径，其中作者还使用“据说”“官方口径”等限定。GitHub 地址是明确资源入口。媒体未看，HTML、3D页面和Word文档的真实质量无法核验。

## 标题承诺与开头

标题承诺开源“用 AI 10倍速学习任何知识”的 Skill，并称由 Qwen3.8 制作。正文提供 GitHub 地址，展示从文章、需求澄清、Skill 结构到“RAG”学习 HTML 的制作链路，开源资源承诺基本兑现；但“10倍速”和“任何知识”没有速度基线或跨主题测试，“Qwen3.8”在正文具体是 Qwen3.8-Max-Preview。开头以读者催更、上一方法反馈和 Fable 额度快速耗尽作为动机，再提出用国产模型做 Skill 并顺带教制作思路，兼有资源领取和模型替代两重钩子。

## 结构与转场

先回顾上一篇十步学习法和读者对 Skill 版本的需求，再解释为何选择 Qwen3.8-Max-Preview及作者对长程执行能力的关注。主体按制作过程展开：接入 Claude Code、放入源文章、写三类需求、用 grill-me 澄清、观察 Skill 架构、生成文件、以“RAG”调用并查看 HTML。随后从主案例扩展到 Three.js 和20多文档整合两个压力任务，最后转向 Token Plan 价格、国产模型替代体验和技术普及观点。主线前半段清晰，后半段由资源教程转成模型宣传和产业感想；“怎么做 Skill”只讲了需求与架构思路，没有展示最终目录、关键文件、调试循环和安装命令。

## 案例：目标、输入、操作、结果与人工成本

案例一为作者亲测制作学习 Skill：目标是把上一篇文章的十步法变成可触发、可检查、可反复调用的能力；输入是完整文章和包含整体、功能、产出三部分的提示词；操作是将 Qwen3.8-Max-Preview 接入 Claude Code，调用 grill-me 多轮明确需求，让模型先抽方法结构图，再把主文件、参考文件和 HTML 要求分工；结果是生成 Skill 文件；人工参与包括提供源文、写初始需求、回答澄清问题和认可结构，具体轮数、修改内容、耗时和成本未给。案例二为作者亲测“RAG”学习 HTML：目标是生成一套可点击学习材料；初始输入仅为“RAG”，模型又询问学习基础和目标深度；操作是只调用刚生成的 Skill，检索包括论文原文在内的资料并生成 HTML；结果是左侧十步路径、右侧详细内容、按钮可跳转，作者评价完整、深入且审美好；作者称一次生成30分钟以上，但未给确切时长、token、价格、引用清单、知识测验提升或人工修正。案例三为作者亲测 Three.js：目标是生成包含程序化沥青道路、车道线、人行横道、多层建筑、路灯、树木、长椅、垃圾桶和车辆的3D街道；输入为文中所列需求；结果据称样式、动效和完成度近乎完美，增加了店铺且红绿灯逻辑正确；未给代码、浏览器性能、报错、人工改动、耗时和成本。案例四为作者亲测超长文档：目标是把 AI+外贸的多 Agent Skills SaaS 思路和20多个文档整合为设计文档；输入是未公开的文档与任务；模型自动从数据收集、产品设计和功能开发拆分，输出格式准确的 Word；作者报告8万字、180页，智能体接管上下文远超1M Token，并含营收计算；未给原始文档总量、计算公式、事实核验、重复率、人工修正、准确率、运行时长和实际费用。“上下文远超1M Token”也未解释是累计读取、压缩还是单次窗口。案例五为模型替代体感：作者把 Qwen 与日常使用 Fable 的读材料、抽方法、调结构和跑产出流程比较，结论是主观上“没有任何区别”；这不是同任务、同盲评的正式对照，没有错误率、用时或成本数据。

## 解释、语言与图文作用

文章用制作日志式叙述，把抽象的 Skill 设计拆成“源文章是唯一信息源—主文件管触发和总流程—参考文件管细则—HTML管交互和审美”，这是最具体的解释段落。语言大量使用“炸裂”“愣了一下”“惊艳”“骨折”等高情绪词，节奏快、带发布感；短提示词和任务原文增强可复制性。模型能力解释更依赖作者体感和结果规模，而不是过程日志或评价量表；“十倍速”“准确、完整”“没有任何区别”等判断缺少定义。对非技术读者而言，Token Plan、grill-me、Skill 主文件、参考文件等术语没有安装和目录示例，门槛仍高。

## 结尾收束

结尾先通过价格折扣说明长程任务中的心理成本变化，再把 Kimi 和 Qwen 的需求与折扣上升为国产模型将成为主要选择的判断。之后引用“科技实力在于使用深度”，以二维码和移动支付类比 AI 的社会渗透，最终落在国产 AI 的力量。随后是公众号互动召回和作者身份介绍。收束具有观点性，但与标题中的开源 Skill 安装使用脱离，未补充版本、依赖、许可证或问题反馈方式。

## 限制与不可照搬处

标题的“10倍速”没有人工学习基线、前后测或完成同一学习目标的时间数据；“任何知识”只用 RAG 一个主题演示。没有展示 Skill 的文件树、核心规则、安装命令、运行环境、许可证、版本号和安全权限，GitHub 内容也未在本文展开。RAG HTML 未展示引用准确率、题目质量、知识掌握提升或学习者反馈。3D 与8万字文档只报告成功结果，没有失败、报错、返工、事实错误、代码性能和商业计算校验。作者明确说生成30分钟以上，但没有token与实际费用；折扣换算“一个token只消耗0.05个”是活动点数表述，不等同货币成本。Qwen参数、正式版开源时间、模型相对排名、版本名称、Token Plan价格规则均未独立核实，且文中使用“据说”“官方口径”。媒体未看，HTML、3D和Word成品不可核验。不能由作者主观体感推导与Fable普遍等价，也不能从文档中的营收计算推导真实预算或收益。

## 可迁移的编辑动作

编辑时可把文章拆成两篇：一篇专讲开源 Skill，给出仓库目录、安装命令、依赖、触发语句、输入输出、调试记录和许可证；另一篇做 Qwen 长程任务测评，统一记录成功率、token、用时、价格和人工返工。学习 Skill 应加入至少三个差异明显的主题测试，并用学习前测、使用后测和延迟复习测量，而不是用 HTML 完整度代替学习效率。超长文档案例应抽样公开来源追踪、数值复算和重复内容检查。适用条件是可公开必要代码、脱敏素材和账单，并明确预览版与正式版不可混写。

## 自己的待测方向（待实操，非已执行）

面向具备基础AI工具使用能力、要在一周内入门陌生技术主题的产品经理，我会用自己的输入测试“向量数据库索引优化”：提供当前水平、目标是能评审技术方案、每天45分钟、七天期限，并准备一套不交给模型的20题前后测。第一步是从仓库固定一个提交版本，在全新环境按说明安装并记录所有依赖和报错。观察点包括是否正确触发十步流程、引用能否追溯原文、内容难度是否随基础调整、HTML交互是否可用、事实错误数、完成时长、token与费用、人工修订分钟数，以及即时和七天后测验提升。所需证据包括仓库提交哈希、完整会话和工具日志、来源清单、生成文件、账单、安装录屏或错误记录、盲评题答案和前后测数据；另用不调用 Skill 的普通提示词作为同模型对照。

## 商业线索与披露

文章重点推荐 Qwen3.8-Max-Preview 与千问 Token Plan，卖点包括长程任务能力、接近作者使用 Fable 的体感、即将发布并开源以及低价活动；还提及 Claude Code、grill-me skill、Fable、Kimi K3、Deepseek V4、GPT-5.6 Sol。明确资源入口是 github.com/idiotLeoLYJ/Daliu-Awesome-Skills。优惠信息为作者转述的白天 Credits 限时1折、个人版夜间在此基础上再享2折，并换算为0.05倍消耗；未给活动日期、套餐价格、上限或官方链接。文章没有明确广告、赞助、赠送套餐、返佣或品牌合作披露，因此合作关系未知；“买了 Token Plan”只能表明作者称自己使用套餐，不能推导是否自费，更不能推导预算、收入或商业回报。
