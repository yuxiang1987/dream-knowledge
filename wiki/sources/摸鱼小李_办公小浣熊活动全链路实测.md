## 定位与证据身份

读者是活动运营、市场策划及正在评估 Work Agent 的职场人。主问题是办公 Agent 能否从调研、画像、策划，连续推进到 Word、PPT、海报、报名 H5 和定时战报，而不只生成好看的演示文稿。文章类型是**单产品、单项目的全链路作者亲测**，也是后续蓝皮书的前置测评。作者亲测包括一句话抓资料、生成画像、跨会话引用、出 Word/PPT/H5、填写测试数据和创建定时任务；“自带浏览器”“积分赠送”和安装体验属于作者观察夹杂产品规则；报告 n=3129 是被 Agent 引用的第三方报告数据，不是作者重新调查。媒体和产物未实际读取，无法核验内容质量及运行状态。

标题承诺“真正适合打工人的 Work Agent 不该只会写 PPT”。正文用从研究到自动战报的一条链路充分回应“不只写 PPT”，且明确把可运行交付放在视觉之前。但“真正适合”需要稳定性、权限安全、数据正确性、价格和多任务成功率，单次案例不足以下定论。

## 钩子和结构

开头直接列“PPT、WORD、H5、调研、战报”，再给出“调研→分析→WORD→PPT/H5→21:00战报”的流程图式承诺，随后先展示成果再倒叙操作。第一节建立研究地基；第二节解释为何新会话用 @ 引用控制上下文；第三节从提案视觉转向报名页可运行性；第四节由活动执行自然进入数据值班。转场句 **“生成物能不能跑通，比漂不漂亮重要”** 是全文标准：把 Agent 评价从审美改为业务闭环。另一关键证据句 **“没检到数英那篇同名报告
，就老实标注用获奖案例替代”** 用一个具体缺失处理支撑“不编数据”的印象。

## 案例拆解

这是一个主案例的六阶段，而不是六个独立成功样本：

1. **调研（作者亲测）**：目标是给观猹开学活动建立情报；输入是一句话，要求到数英找报告、观猹找热门产品与评价、再抓两个标杆案例；操作由 Agent 浏览网页并把笔记存本地；结果为9分钟、12个文件，并标注未找到同名报告而改用获奖案例。人工成本看似只有下指令和检查，但未披露提示词全文、登录、清洗、事实核验和错误文件数量。
2. **用户画像（作者亲测＋第三方数据）**：输入前述材料和《2025年大学生使用AI行为与生态洞察报告》；操作是合并报告与观猹数据，要求表格和可入方案的图；结果声称样本 n=3129，并把付费矩阵标为定性判断。调研加画像共20分钟、1172积分。缺失报告来源链接、抽样方法、数据字段、合并逻辑与图表准确性核验。
3. **Word策划（作者亲测）**：目标是完整活动提案；操作为新建会话并 @ 前一阶段调研，Agent发现真实活动“搭子进行时”后扩展为开学季特别场；结果12.5分钟、1730积分，主题、玩法、节奏和权益齐全。缺少总页数、人工改字量、事实错误和可执行预算。
4. **PPT/VI/海报（作者亲测）**：第一轮13页、10分钟、QA零警告；作者认为封面不符合品牌，要求读官网 CSS、抓 #33A66D、下载 IP 并写 VI 规范后重做，另生成主视觉和7天打卡手卡。人工介入至少包含一次审美否决和追加提示。QA零警告只说明工具规则未报警，不等于品牌方认可或事实无误；重做时间和积分缺失。
5. **报名H5（作者亲测）**：输入主视觉、三个赛道和表单要求；结果为本地页面，作者填入测试数据并取得编号 DZ-MONEY-35695。该动作支持单次表单路径跑通，但缺少移动端兼容、数据持久化、安全、并发、隐私告知和真实部署。
6. **定时战报（作者亲测但未完成运行验证）**：目标是每日21:00汇总报名 CSV 与打卡记录生成 MD；操作是在界面选时间保存；结果只明确“任务已创建”和历史可留痕。由于活动尚未开始，没有证据证明定时触发、数据汇总正确或失败恢复有效。

## 边界、表达与商业信息

文章最有价值的是把工作拆成有依赖关系的中间产物，并用新会话＋引用避免所有材料挤在同一上下文。但“@引用能省上下文”是操作解释，不代表模型绝不会遗漏。一次成功也不能证明“跨平台管理”稳定；浏览器抓取还涉及来源授权、网页变化和敏感数据风险。文章没有与人工流程或其他 Agent 的同口径基线，不能认定爆文、效率领先，也不能把任何传播归因于产品。

语言以“抓情报、烧钱、值班”等运营口语降低技术门槛，数字标签强化可量化感。截图应承担文件、图表、PPT、H5和任务设置证据，但未看媒体，不能描述其视觉或核验内容。结尾重申浏览器操控、办公套件、定时任务与积分透明，并给领取额度和兑换码，明显转入促用。

商业产品为办公小浣熊网页端/桌面端；卖点是浏览器抓取、Word/PPT/Excel、多会话引用、H5与定时任务、积分明细。入口表述为登录网页端和安装桌面端；新老用户各可领6000积分，代码 JHPQJP5GWO 再兑1000积分，均为作者报告，未核验有效期与条件。文章未明确披露赞助、返佣或合作，关系未知。

## 可迁移动作与待实操

候选是“阶段产物落盘＋新会话定向引用＋每阶段独立验收”。我的五要素：**目标读者**为活动运营；**自己的输入**为真实品牌规范、三份来源材料、报名字段和脱敏样例 CSV；**第一步**先建证据表，记录每个结论的 URL、日期与原句；**观察点**为引用正确率、人工修改分钟数、H5表单成功率、定时任务连续7天成功率；**所需证据**为全量提示词、文件版本、运行日志、人工修订记录、积分与时间账单。

### 逐字锚点核验

- 「没检到数英那篇同名报告，就老实标注用获奖案例替代。不编数据，只拿当时能抓到的。」——01「调研和分析不能省」抓情报结果段，支持Agent在未检索到指定报告时标注替代来源、而非虚构数据的作者观察。
- 「三个赛道：AI 学习搭子、社团搞事、校园搞钱。我填了条测试数据，顺利拿到搭子编号DZ-MONEY-35695。」——03「提案能看，落地能跑」报名H5测试段，支持作者实际提交一条测试数据并跑通单次报名路径的判断。
