# 摸鱼小李_百灵健康大模型六病例对照实测

## 主问题与证据身份

- 原题《6 个真实病例，实测百灵开源的健康大模型会不会「看病」》，raw 署名为“点击关注👉”，账号摸鱼小李（`gh_3923025946c5`），发布时间 `2026-11-24 11:30`，[微信原文](https://mp.weixin.qq.com/s?__biz=MzA5OTIzMTE1OA%3D%3D&mid=2247492243&idx=1&sn=8a7b5df49116a5efec380be9871b1d41)。核对原链、原题与正文，未见同作品旧 source，独立新建 source 页。
- 实际阅读范围：通读 raw 全部可提取正文文字 P1—P233 及末尾 6 病例五步临床推理评分表；原文含 34 张图片占位（含问诊长截图、CT/MRI/显微切片及生态大会照片），**图片与长截图全文未核看**，未调用蚂蚁数科 MaaS 接口或验证医疗诊断准确性。
- 读者：关注开源专用医疗大模型（本地隐私部署）与闭源通用旗舰模型在真实问诊推理与多模态读片上差距的 AI 从业者及健康应用观察者。主问题：蚂蚁阿福开源的百灵健康模型（`LingSante-3.1-air-VL` 与 `LingSante-3.1-flash`）在真实多轮问诊、影像判读与危机筛查上表现如何，与 Claude Opus 5.5 相比差距在哪里？
- 主分类：实操测评；主研究对象：百灵健康大模型（`LingSante-3.1-air-VL` 124B/5.5B激活/256K上下文 与 `LingSante-3.1-flash` 560B/25B激活/1M上下文，对照 Claude Opus 5.5）。
- 逐项证据身份：
  - **发布与规格转述**（未独立核实）：11 月 20 日 Levent Alpöge 与 Claude 数学证明消息；11 月 23 日蚂蚁阿福开源两款百灵健康模型的参数与分工；蚂蚁阿福健康生态大会上超聚变 FusionXparkGB10 与微软 Surface LaptopUltra 本地方案展示。
  - **作者亲测自述**（长截图未核看）：找医学朋友提供 6 个脱敏真实病例，通过蚂蚁数科 MaaS 平台 OpenAI 兼容接口接入自建本地测试工作台，按症状难易逐轮对话并送入影像图/病理图测试——CASE 01 花斑癣（6 秒给出最像汗斑，对比 Opus 5.5）、CASE 02 脓癣（3 轮文字+头皮照+3 张真菌图，对比 Opus 5.5）、CASE 03 自发性低颅压（3 轮推翻急诊“贫血+低血压”并看懂 MRI 硬脑膜强化，对比 Opus 5.5）、CASE 04 5cm 鱼刺致肝脓肿（5 轮追到旧胸部 CT 线状高密度影但未把鱼刺排第一）、CASE 05 乳糜泻（3 轮抓住高炎症低铁蛋白+阻止提前忌口+读活检，但首轮未提先查抗体且未能仅用乳糜泻解释高烧）、CASE 06 乳腺癌化疗营养咨询（3 轮识破“靠吃升白细胞”和化验单缺白蛋白陷阱并计算蛋白缺口 15–30g）。
  - **临床五步评分自评表**：作者自制五步临床推理（确定问题→列出可能并排序→先查最要命的→用检查验证→新结果重排）成绩单。

## 标题与开头

标题用“6 个真实病例 + 实测百灵开源健康大模型会不会‘看病’”明确样本数、材料来源与核心悬念，且给“看病”加引号保持分寸。开头 P1—P7 从 11 月 20 日 AI 解开 167 年数学难题拉回自己“常连觉都睡不够”的日常健康问题，顺势介绍 11 月 23 日阿福开源两款健康模型的规格，P8 交代“医学朋友提供脱敏真实病例 + 3 题对照 Claude Opus 5.5”，P9—P15 结论先行。

标题兑现情况：正文完整跑完 6 个逐步加难的多轮病例且在前 3 题附带 Opus 5.5 对照，不仅写了做对的地方，还在 Case 04、05、06 及总结表里明确列出“没把鱼刺排第一”“首轮跳过查抗体直接建议活检”“遇到不典型疑难病例最后一步还是差一点”，标题兑现扎实且克制。

## 结构推进

宏观热闻引出健康需求 → 模型开源规格与本地工作台准备（附免责声明） → 3 条核心结论 → CASE 01–03（简单皮肤病→宠物真菌多轮→推翻急诊判断，每例配 Opus 5.5 对照） → CASE 04–06（疑难异物感染→非典型发烧乳糜泻→肿瘤化疗营养防踩坑） → 临床五步成绩单总表 → 总结能力与 Opus 5.5 差距 → 院内/家庭本地隐私部署愿景与阿福生态飞轮收尾。

推进亮点在于**前 3 题用 Opus 5.5 建立外部参照系，后 3 题专门拿真医生当年也容易漏或家属会踩坑的复杂多轮病例测临床推理深度**，并用一张“STEP 01–STEP 05”成绩单把“做到/部分做到”可视化。

## 原文定位锚点

- P8，测试方法与对照组说明：`为了保证测试的真实性，找了几个医学朋友，提供了脱敏的几个病例，从易到难跑了一遍。其中 3 道，拿我的Claude Opus 5.5 也测了下`
- P18，真实接口环境坦白：`用蚂蚁数科 MaaS 平台的 OpenAI 兼容接口，接到我自己搭的一个本地测试工作台`
- P219—P220，能力边界与差距自承：`常见到复杂一点的病例都跟得上，但遇到不典型的疑难病例，最后一步还是差一点。当然，它不是医生，也不能和不会代替医生，最后的诊断和治疗还得交给医院` / `和 Claude Opus 5.5 对照的 3 道题，最后的判断都一样，差距主要在一些推理和细节上，客观上是存在差距的`

## 结尾怎样收束

先用“像真人医生一样按五步问诊 + 先排除最要命风险”归纳模型表现，承认与 Opus 5.5 在推理细节上有差距、突出开源与院内数据不出门的价值，再用生态大会上的桌面超算/笔记本展示引出社区医院与“家庭医生模型”愿景，最后回到阿福入口与“每个人的健康才是人生最重要的事”。

## 失败、限制与不宜照搬处

- 失败与扣分留存：作者明确保留了 Case 04 始终未把鱼刺排在第一、Case 05 首轮直接建议内镜活检而漏掉先抽血查抗体、Case 03 脊柱积液未点明，以及“整体与 Opus 5.5 推理细节有差距”。
- 测试条件不对称：作者强调“开源可本地部署、数据不离开电脑”，但本篇 6 例实际是通过**蚂蚁数科 MaaS 在线 OpenAI 兼容接口**跑的，并未验证本地硬件（124B / 560B MoE 所需显存、内存与本地推理速度）；且后 3 道最难的病例没有跑 Opus 5.5 对照。
- 医疗安全红线：部分提取块存在 SVG 内文字截断（如 P48、P71、P158、P174 等处被引号留空，实为截图或强调词在 SVG 中）；任何 AI 医疗输出都不能替代执业医师诊断，本库不可直接采信医疗个案结论或自行诊断。
- 不宜照搬处：不得移植作者“常连觉都睡不够”“找医学朋友要病例”的个人人脉与故事；单篇互动快照为阅读 31624、点赞 155、老赞 292、转发 611、收藏 110、评论 54（n=1），不构成基线或传播因果，未测本账号读者效果。

## 可迁移写法与自己的待测方向

- 可迁移动作：测垂直领域模型时，把单纯的“答对/答错”升级为“**领域专业思考五步拆解表**”（例如临床思维五步：定位问题→排序鉴别→先排致命风险→检查验证→新信息重排），并把“做到”与“部分做到”分开标色；在夸开源隐私优势时，主动交代本次测的是在线 API 还是本地机部署。
- **待实操**：面向评估专业垂类知识助手或开源小模型的读者，以公开权威医学/科普教材中已公布的 3 道标准脱敏教学问答题（不含真实患者隐私，事先备好“高危红线警示 + 必问追问项 + 检验优先级”金标准清单）为输入。第一步在不告知最终答案的前提下，分多轮向待测开源模型与闭源对照组输入信息。观察两模型是否先提示高危红线、信息不足时是否主动追问而非直接下结论、面对矛盾线索能否推翻前判以及响应耗时。需保留全部提示词、脱敏文本、模型版本、接口日志与评分对照表，不用于任何真实医疗决策，未验证本账号读者效果。
