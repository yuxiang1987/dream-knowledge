# 卡兹克MiMo模型选择文章拆解

来源：`raw/article/kazike/今夜的荣光属于MiMo V2.6。.md`，原文署名时间 2026-09-22 10:02，卡兹克、AIZ小朱。本页分析文字；榜单截图、动图和技术报告未逐项核验，未独立实测。

## 它讲什么

主问题：在性能、价格、速度难以兼得时，新模型会怎样改变实际业务中的模型分工？原文把同夜发布的 Grok 4.7 与 MiMo V2.6 放进同一个个人选择框架。

## 关键要点

- 开头从 GPT-6 Astra 强、贵、慢的自用困境提出“不可能三角”，随后用对 Grok 的高预期落空、对 MiMo 的低预期惊喜制造反差。
- Grok 一节分别讨论原文所引 AA 指数、Coding Agent 与科研推理测试、前端视觉案例和价格；MiMo 一节沿相似维度展开，而不只比总分。
- 作者称 MiMo Pro 的 AA 分数为 46，缓存输入价格为每百万 Token 0.025 元，并述及约 130 Token/s 输出速度。这些都是文章当时引用或自述的产品口径，不是本库当前推荐参数。
- 私有 AIHOT 约两千题的筛选测试，是作者迁移后端判断 API 到 Flash 的直接动机；另有定位 BUG、建筑前端、花朵动效等自述案例。
- 正文继续介绍后训练直播、技术报告、桌面客户端和开源模型、任务环境，把“能用”扩展到“可研究”。文中说热点算法重构仍在执行，CI 曾退回一次，没有给出最终完成结果。
- 工作流收束为：高风险算法与大型重构仍交给更强模型，普通功能和 BUG 考虑 MiMo Pro，批量判断考虑 Flash，未来还要比较其他模型的性价比。

## 写法与可复用方法

**先定义选择维度 → 两款产品同维对照 → 进入自己的业务 → 说明迁移决策 → 保留高风险场景**，比排行榜介绍更有读者行动价值。文章也区分厂商自己的细项跑分与外部榜单口径，提醒“看看就行”。

值得复用的是把模型选择拆到任务风险、调用频次和延迟要求，而不是宣布一个绝对王者；不足是强情绪和“无脑切换”等口语容易掩盖迁移需要的质量门槛。

## 证据边界与疑问

历史版本、参数、价目、榜单名次、开源范围与“降低成本50%”未独立核实，也不代表当前状态。私有测试没有完整数据、评分标准、并发与网络条件，无法推导普遍优势。尚在运行的重构不能写成已成功交付。技术报告地址是原文给出的追溯线索，不等于本轮读过报告。
