### 标题承诺与开头

标题以“首批实测”和“夯爆了还是拉完了”制造强烈二选一悬念。开头先陈述架构、上下文、AA 分数和价格等产品主张，再列举官方案例，随后转入作者自己的 SVG 鹈鹕和 Agent 工作台测试。核心承诺是展示从读图、整理需求到前后端开发、测试的全过程。正文提供了操作链、一次可复述的 bug 修复、耗时、请求量、Token 与费用计算，基本兑现；但“黑马”“长任务稳稳拿捏”等评价超出单案例可证范围，官方指标也未独立核验。

### 结构推进

先用模型参数、评测和价格建立产品期待，穿插官方 3D 象棋、代码绘画和历史图册案例；再以作者“手痒”转入亲测。主体按 Claude Code 接入、准备原型图与 PRD、整理需求文档、接口文档、后端、前端、功能测试推进，编号从02跳到04，文字未解释03缺失。每阶段都用“我让模型做什么—模型如何处理—作者如何检查”展开。结尾汇总成品判断，再公布时间、请求、Token、缓存命中和费用，最后介绍体验权益、邀请链接、奖励及开源计划。

### 逐例证据与人工成本

- 作者亲测主案例：目标是把此前的桌面端 AI Agent 工作台原型做成可操作项目；输入为一张原型图和作者自写的简短 PRD，操作是通过 Claude Code 接入 Step 5 Preview，先整理需求与接口文档，再生成 Node.js+Express 后端和 HTML/CSS/JavaScript 前端，启动服务、调用接口并检查交互。结果按作者描述为前后端已接通、页面可操作、数据可落盘，整体布局基本还原。人工参与包括写 PRD、提出持久化与测试要求、检查状态信息、试用页面和反馈 bug；未给人工操作净时长。总任务耗时2小时7分钟、306次请求，输入约4524万 token、输出约24.4万 token，作者按公布单价算 API 费29.47元；证据身份为作者亲测，但图片和运行环境未由本文外部核验。

- 缺陷修复子案例：输入操作是右侧文件预览栏“先点展开，再点关闭”；首次结果为无法关闭，且中间对话区未变宽。作者将复现步骤与问题发给模型，模型修改后，作者按相同顺序复测，结果为右栏正常收起、对话区铺开。人工修正体现为作者发现、描述并复测，模型具体改动、修改轮数和该步骤独立耗时未提供，成本仅包含在总费用中；证据身份为作者亲测。

- 官方案例材料包括3D中国象棋、p5.js《清明上河图》和1922年旅行指南交互图册；正文只是作者转述“官方实测”，未给完整提示词、代码、耗时、成本与人工修改，证据身份为官方主张整理，不能与作者工作台实测合并证明。

### 解释、观点与可证范围

作者把顺利完成归因于模型能读图、在图片过大时自行切图、从简短 PRD 补全需求、生成全栈代码、启动服务自测，并主动对比渲染页与原型。可证范围仅限作者叙述的这一次任务及其检查动作，且视觉还原度包含明显主观判断。600B总参数、每 Token 激活27B、1M上下文、AA 44分、相对成本比例、协议兼容和未来开源均是产品或官方层面的主张；正文没有给评测版本、完整基线、复现实验和独立核验，不能直接推导为普遍能力。缓存命中与费用有作者给出的数字和算式，但仍缺账单截图及计量口径核验。

### 语言、图文与结尾

语言高度口语化，频繁使用“好家伙”“手有点痒”“挺省心”等情绪词，步骤标题让长文保持推进感。文字可确认媒体承担了原型输入、页面对照、架构展示和界面结果展示的角色，但图片、视频、音频未观看，不能评价其具体视觉细节或证明运行结果。结尾先给正面体验，再用精确消耗数字建立可信度，随后自然切入套餐、免费权益和邀请注册链接，最终以国产模型竞争和开发者受益的情绪句收束。

### 限制和不宜照搬处

单一项目、单一作者环境不足以证明模型在长任务编程上普遍稳定；没有公开完整 PRD、全部提示词、代码仓库、测试用例、依赖版本、机器环境、模型快照或逐请求日志。作者称暂未发现其他问题，不等于不存在问题；没有安全、并发、异常恢复、数据一致性和长期维护测试。原型图和成品图未观看，无法独立判断还原度。官方参数、评测排名和成本比较未独立核验，也没有与 Kimi K3、GLM 5.3、Claude Opus 5 在同一任务上的对照。

### 商业线索

产品为 Step 5 Preview、StepFun 开放平台和 Step Plan，Claude Code是接入工具。读者任务是试用模型并完成 AI 编程项目；卖点包括长任务开发、协议兼容、缓存低价、免费体验权益及计划开源。入口行动很明确：创建 API Key、按官方文档配置，或通过作者邀请链接注册并完成首次调用。作者明确披露“也算顺手帮我续上15天，我这边同样能拿到邀请奖励”，因此可确认存在邀请奖励利益关系；正文未明确称品牌付费赞助或广告，是否另有商业合作未知。
