# WorkBuddy七处设置教程定稿

归档文章《WorkBuddy 做好这几个设置，让WorkBuddy越来越懂你》。这是一篇配有桌面端截图的设置教程。定稿正文按本地检查口径为 2772 个有效字，原稿有 12 张配图和一份可复制的自定义指令。当前归档状态为已定稿、已排版，公众号发布链接和发布效果未核实。

## 七处设置

| 设置 | 可复用要点 |
| --- | --- |
| 存储路径 | 先分清程序装在哪、默认工作空间放在哪、对话记录和运行缓存放在哪。文中展示的是修改新建任务与分组的默认工作空间，旧任务和系统缓存不随之迁移。 |
| 给 WorkBuddy 的指令 | 把经常重复交代的要求写在「个性化」。原稿保留了偏编程的四条规则，分别是先想清楚、保持简单、只改必要部分、完成后核对结果。 |
| 回复风格 | 文中举了「专业严谨」「高效务实」「启发引导」三个例子，用是否需要细讲、快速给结论或继续梳理需求来解释选择。 |
| 人设设定与长期记忆 | 人设约定希望它怎样沟通，长期记忆保存后面可能还用得到的背景与偏好。定稿把两项放在同一节。 |
| 记忆与进化 | 用周报说明三件事。通用偏好可以复用，项目统计口径只留在对应项目，已经跑顺的重复步骤可以做成 Skill。 |
| 窗口设置和模型选择 | 简单任务先用默认设置。需要反复推敲时可试着调思考强度，交付后仍核对结果。分多次做的任务把关键进度和资料写入台账，下次接着做。 |
| 数据导入 | 记录桌面端「设置 → 数据导入 → 导入其他应用数据」的入口。截图显示客户端识别出的应用和可选的导入类别。 |

## 可复用的写法

- 开头用地铁广告和身边家长问用法引入，再落到读者自己的问题：装完就用、换个对话又要重新交代。地铁图在排版中紧跟提到广告的那句话。
- 每节尽量用「遇到什么情况 → 到哪找设置 → 可以怎样用」推进。周报例子一次讲清个人偏好、项目约定和可复用流程。
- 跨会话接续的台账只记四件事：做完的事、已经定下的方案、相关文件的位置和下一步。下一轮只需引用较少材料时，有机会减少重复带入历史消息。这里没有积分对照数据。
- 结尾保留作者对现成专家、技能和连接器的个人判断，将工作流实操留作后续选题。
