## 它讲什么
本文的核心问题是：AI Agent 能否不止问答，而是跨手机、电脑、云端、飞书和邮箱接下一段完整办公流程，并把重复规则沉淀为 Skill，从而支撑小团队或“一人公司”。分类为**办公 Agent 实测＋工作流教程＋权益导流**。主要对象是独立产品“豆包工作/豆工”，关联豆包桌面版、飞书云盘与连接器、QQ 邮箱、云电脑和办公 Skill。证据以作者数日使用和公司真实资料为主；“网友们亲切地称他为‘豆工’”、部门合并等是外部语境；多端、权限与默认 Skill 等能力既包含作者操作，也包含产品层面的主张。未观看操作录屏、PPT 和信息卡片，无法独立验证完成质量。

## 标题、开头与兑现
标题声称“跑了几天日常办公”并“把 AI 一人公司搭起来了”。正文覆盖选题调研、群内信息卡、口播文案、公众号数据分析、PPT、发票、邮箱、机器人等，任务广度兑现；但“搭起来”是作者对初步工作流的感受，并非公司可脱离人工自主运营。结尾主动收窄为“真实的同事还在一起讨论、判断和做决定”，因此一人公司更准确的含义是 AI 小队辅助，不是无人公司。开头以周日躺床上、手机派活、回电脑已完成大半制造强场景，然后插入“文末会员领取方式”，很早暴露转化意图。

## 结构、转场与语言
结构从生活助手人格化切入，介绍入口与账号差异，再讲多端及飞书连接，继而铺开五类公司任务，重点详述选题、写稿、数据 PPT、Skill 和邮箱，最后回到人机分工。转场逻辑是“从聊天到办事—从单任务到资料系统—从一次任务到可复用 Skill—从内容主业到行政杂活”。语言大量拟人化：“穿上工服”“小豆包像是突然长大了”“书包”，使复杂集成更易传播；同时长任务指令中加入来源优先、去重、“待核验，不要猜”，体现作者真正的编辑规则。文章优点是输入写得较具体，缺点是输出验收证据、耗时与失败率不足。

## 逐案例拆解
1. **入口与多端**：飞书账号登录默认进入豆包工作并连接飞书云盘；豆包 App 扫码登录可保留聊天记录并进入工作任务。作者把本地电脑定义为适合访问本机文件和软件，云电脑适合离开后持续运行。具体支持系统、电脑保持唤醒的安全风险、云端费用和任务中断率未提供。
2. **选题调研**：目标是最近一周 AI 工具、Agent、办公、视频领域的可写选题。输入包括语音任务、时间范围、官方来源优先、原始链接、发布时间、热度/价值/证据/媒介分类、飞书已有选题表，以及 Agent Reach、AI Hot 等本机 Skill。操作是手机下达、电脑保持唤醒、过程中补充排除二手转载和普通新闻，最终写入飞书、做对比表和群信息卡。作者回到电脑后只需抽查来源、挑最终选题；这也说明仍需人工核验。任务实际运行分钟数、找到多少候选、多少待核验、错链率和去重准确率未提供。
3. **口播文案**：选题确定后继续生成可拍稿。作者评价“比较有人味”，人工动作是稍微润色并补自拍视频素材。原稿、修改比例、拍摄成片数据和耗时未提供，故不能判断是否接近直接可用。
4. **公众号数据与 PPT**：输入为近两个月真实公众号数据表，操作是分析并调用默认“飞书幻灯片专业版”Skill；用途是商务展示和账号复盘。作者称简洁、重点直观。没有披露指标口径、数据清洗、图表错误、PPT 页数、生成时长或甲方反馈；更不能从“真实数据”推出分析必然正确。
5. **Skill 化**：将官方来源优先、避免重复、兼顾普通人兴趣等编辑经验固化，以后替换时间和主题。作者还报告豆包可读取电脑里已有的 Agent Reach、AI Hot Skill。跨 Agent 兼容范围、权限机制、失败记录和版本冲突未提供。
6. **邮箱发票**：连接 QQ 邮箱需授权码，目标是找发票并整理到飞书多维表格。这是高价值但高风险任务，文中未说明附件识别准确率、重复发票、币种税额核验、敏感邮件隔离和人工复核。飞书机器人虽列入测试范围，却没有具体案例结果，应明确为未展开。

## 证据身份、商业信息与结尾
作者亲测包括账号入口、手机派活、选题文档、信息卡、口播、数据 PPT、Skill 与邮箱；官方或产品性主张涉及独立 Agent、多端互通和默认能力；第三方信息包括网友昵称及组织合并语境。商业产品是豆包工作，卖点是任务拆解、多端续跑、飞书资料闭环、可编辑结果、Skill 复用和连接器。入口有独立电脑版、豆包桌面版“工作任务”、飞书账号登录及连接器。明确促销为“限时领取30天订阅权益”，但未给价格、截止日期、资格限制或链接。文中没有明确说明是否广告合作、媒体邀约或权益置换，披露状态未知。结尾正确地把人保留在目标、判断和审美层，把 Agent 放在重复和耗时过程，避免把自动化夸大成全面替代。

## 限制与传播
文章没有给普通聊天 AI、人工流程或其他 Agent 的同口径基线；也没有连续多次成功率、端到端耗时、错误率、权限审计和隐私说明。因此不能称已证实“一人公司”完成搭建，更不能把个别成功输出推广到财务、合同等高风险任务。开头“躺床上派活”、圆润豆包人格、多端续跑和真实公司杂活形成强代入感，具备传播性；“30天订阅权益”则承担转化。无集中失败案例，只有“仍可能理解错”“需要抽查”“稍微润色”等轻度保留，故应写明未提供系统失败记录。

## 个人待实操五要素
**目标读者**：使用飞书、有固定内容流程的 1—5 人团队；**自己的输入**：一张脱敏选题表、十篇历史内容、明确来源白名单和一套评分规则；**第一步**：只开放只读文件夹，先跑最近七天选题任务，不接邮箱写权限；**观察点**：来源原始性、发布日期、历史去重、待核验标注、群消息是否发给正确对象；**所需证据**：人工与 Agent 各跑三轮，记录总耗时、候选采纳率、错链/漏链数、人工改字比例和权限日志。发票流程还需逐字段人工核对后，才可考虑扩大权限。
