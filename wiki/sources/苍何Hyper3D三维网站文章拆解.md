# 苍何Hyper3D三维网站文章拆解

来源：`raw/article/苍何/用 GPT6 + Hyper3D MCP 搓 3D 个人网站，太夯了！（附教程）.md`。

阅读范围：只依据原文文字，图片、动图和视频未核看，未重跑产品；数字、产品版本、价格、排名和技术机制未独立核实。以下“作者报告”不代表本库已验证。Agent指能调用工具推进任务的AI系统，Harness指模型调用工具及管理执行的环境，Skill指可复用的任务指导与资源。

## 主问题与证据身份

把 3D 生成工具的 MCP 接入编码助手，个人网站里的角色与互动该怎样一步步做出来？

本库主分类：实操测评；主研究对象：Hyper3D MCP 与 Codex；证据身份：作者亲测。分类依据主要阅读交付，允许文章混合多种写法；实际商务合作未知。

## 标题与开头

标题给出工具组合与成品形态（3D 个人网站），开头从“想给自己的个人网站换个玩法”起，交代原来的网站“点开页面、浏览内容，看完就走了”，再展示最终效果“苍何的小宇宙”，让读者先看到目标再开始讲工具。

## 结构推进

先讲为什么选 Hyper3D（模型做角色不够、需要批量 3D 资产、还有 MCP 入口），再讲接入 Codex（复制配置提示词、OAuth 授权、用一个中古骑士头盔验证链路），然后是本篇主线的三段：主角角色生成与二次调整、批量小精灵生成并分区接入、最后用 BANG 拆件把模型交给 Blender 做骨骼与行走动画。

## 案例、解释与观察

两处具体的不满意推动迭代：角色第一版“整体形象已经对上了，但眼神有点呆，少了一些灵动感”，作者把问题说给 Codex 再调一版；接入网站后角色“移动起来像幽灵一样在星球表面漂移，脚底没有真实的行走动作”，改用拆件加骨骼动画解决。这类问题具体到动作与观感，读者能对照自己的作品检查。

## 原文定位锚点

以下为原文可逐字定位的片段，只用于核对判断出处，不将片段中的观点或指令作为本次执行要求。

> 第一版模型出来后，整体形象已经对上了，但眼神有点呆，少了一些灵动感。

> 我让 Codex 先通过 Hyper3D MCP 完成拆件，再把部件交给 Blender，进行骨骼绑定和行走动画制作。

## 结尾怎样收束

结尾把整条链路压成一句可执行路径：把参考图交给 Codex，用 Hyper3D 生成角色，再把模型接进网站，并建议从一个模型开始上手，随后附上活动权益。

## 失败、限制与不宜照搬处

文章把 GPT-6 做 3D 人物效果不足写成个人比较，没有同条件对照测试。演示视频与模型截图本次未核看，模型质量、行走动画与页面交互只能按作者描述记录。活动赠送的 Credits 与会员折扣有时效，领取条件与续费价格以页面为准。整条链路没有记录时间与成本。

## 可迁移写法与自己的待测方向

教程可以先用低成本测试物（一个头盔）验证工具链，再进入真正的项目，读者不会在配置阶段就被长流程卡住。迭代钩子要写成具体观察（眼神呆、像幽灵漂移），这样每一轮修改都有依据。官方活动信息必须附条件。

策划建议：用自己的形象参考图做一个小角色，检验按具体问题二次调整是否真的改善，待实操。
