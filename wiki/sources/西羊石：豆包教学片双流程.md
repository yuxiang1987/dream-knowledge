### 它讲什么
文章解决的主问题非常具体：老师只是偶尔需要几十秒到一分多钟的教学视频，却要跨越脚本、画图、配音、视频生成与剪辑多道门槛，怎样把多工具工作流压缩成聊天式操作。它属于“桌面 Agent 全流程教程＋产品体验”，主要对象是不会剪辑的教师，以及希望保留后期控制权的轻度创作者。证据主体分三层：作者亲测的英语介词动画和苏轼《定风波》短片；豆包工作、Seedream、Seedance、剪映工程能力等产品功能描述；有关“零门槛”“最厉害”“AI 已经完成了80%”的评价。后两类均是作者陈述或产品口径，不是本库独立验证。

### 标题与开头兑现
标题承诺“动动嘴”“自动剪辑”“全流程教程”“附提示词”，正文基本兑现：给出两个完整流程、三段可复制需求文本，并交代 FFmpeg、Python、Jianying Editor 等后台执行方式。开头先写老师为一分钟视频注册账号、熟悉界面的成本，再用“用平时聊天的方式就把片子做出来了”提出解法，痛点与产品能力衔接直接。需要注意，所谓“动动嘴”实际仍包含建项目文件夹、选 Skill、审分镜、审资产、筛视频、装 GitHub Skill、打开剪映微调等操作，因此它是低操作门槛而非真正零劳动。

### 结构、转场与语言
结构是“痛点—成片钩子—简单案例—进阶案例—价值升华—下载权益”。第一案全自动交付 MP4，第二案交付可编辑剪映工程，难度递进清楚；“如果做的是素材更多、带剧情的短片”承担关键转场，把用户需求从省事切换为可控。语言口语化，频繁使用“敲黑板”“有手就行”“哈哈”等降低技术距离，同时用“文-资-视-剪”概括专业流程。结尾由操作教程上升到“技术终于退居幕后了”，情绪有效，但也弱化了审核、返工和生成成本。

### 案例逐项拆解
**案例一：英语介词动画（作者亲测）**。目标是给低年级学生做约25秒、横屏、无初始背景音乐的 in/on/under 动画。输入包括教学目标、橘猫连续动作、三句英文、字幕突出词、结尾提问和3秒停顿。操作是建本地文件夹，选择官方“短剧创作”Skill与豆包2.1 Pro，先审项目规划、旁白脚本和分镜，再审角色设定、场景、关键帧，之后由 Seedance 2.5 生成视频，最后以 FFmpeg 拼接合成、Python 制作字幕图并检查音量。结果据作者称为可下载 MP4，素材和成片保存本地。人工修正明确有一次：把白色围脖改成带铃铛红项圈；还要求用户检查位置、句画对应、画风与场景。总耗时、生成轮数、积分或订阅成本均未提供；也未提供失败记录和课堂学习效果。

**案例二：苏轼剧情短片（作者亲测）**。目标是一至一分半、写实古装电影感的《苏轼的一场雨》，并留下可编辑剪映工程。输入是《定风波》及小序、情节节奏、对白边界、竖排诗句和镜头要求。操作先安装第三方开源 Skill“jianying-editor”，再生成规划、人物小传、剧本、角色和场景资产；作者上传赵孟𫖯所绘苏轼图作人物参考，生成6段、每段15秒的视频，人工筛选可用素材到指定文件夹；随后让 Skill 按故事而非文件名剪辑，保留原声、安排字幕、诗句、音乐和片尾余韵。结果是约十三分钟生成本地草稿，Windows、Mac据称均支持，但 Mac 需手动导出。人工修正包括初版人物气质不符、偶发穿帮需重生、筛素材、在剪映微调，以及不喜欢两首AI配乐后改用剪映云端音乐。十三分钟只明确指草稿创建，不等于全片从零制作时长；素材生成、审核、重生与安装时间未提供。所谓“80%”没有统一任务拆分与同口径人工基线，不能视为已证实效率提升。

### 官方主张、第三方与商业信息
Seedream、Seedance、豆包声音模型、云端电脑、手机远控等能力在文中以作者使用叙述出现，但稳定性、版本限制、额度和隐私边界未测试。Jianying Editor 是 GitHub 第三方 Skill，文章未讨论代码安全、剪映版本兼容长期性或素材上传权限。商业产品是豆包工作；任务是教学动画和剧情短片；卖点是一处调用多模型、聊天修改、自动剪辑、可交付本地文件或剪映工程；入口是网页搜索“豆包工作”下载电脑端。文末给出“新用户限时免费领取30天订阅权益”及续领信息，明显具有导流性质，但未明确标注广告、赞助或合作，合作披露状态只能记为未知。

### 结尾、限制与传播判断
结尾将教师的课堂设计能力与工具自动化对置，适合教师社群传播；双案例、完整提示词、福利提醒也增强收藏和转发动机。但正文没有成片画面的可核验文字指标，且图片、视频未观看，不能评价视觉质量、角色一致性、字幕准确率或口型同步。没有人工制作的同任务耗时、成本和质量基线，也没有阅读量、完播率、转发率数据，因此不能称其已证实“爆文”或证明效率优势。还应补充版权风险：网上人物参考图、剪映云端音乐、诗词改编和模型素材的授权范围均未展开。

### 个人待实操五要素
1. **目标读者**：第一次做教学视频的小学英语教师。  
2. **自己的输入**：一页介词教案、三句标准文本、角色设定、25秒时长及无BGM要求。  
3. **第一步**：建立独立项目文件夹，用文中英语提示词跑官方“短剧创作”Skill，但先停在分镜审核。  
4. **观察点**：三种空间关系是否一眼可辨、同一橘猫是否一致、英文发音与字幕是否准确、结尾是否真的留满3秒。  
5. **所需证据**：全流程计时、积分/订阅消耗、每镜重生次数、教师盲评、学生理解前后测，以及同一素材用传统剪辑完成的基线。
