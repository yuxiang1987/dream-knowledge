## 标题与开头

标题“谷歌真争气啊，这下可以爽用Gemini了。”偏重情绪赞叹，但开头 P7—P14 并没有无脑吹，在宣布黑五 50% 折扣和缓存命中率提升 4% 的好消息后，立刻吐槽 Antigravity 的“重置卡是纯营销、对 500 刀订阅用户是伤害”，态度鲜明地把“优惠/缓存”和“营销套路”分开。

标题兑现情况：正文通过“5 个外网 Neon 作品展示 + agy 省 Token 实操配置（Orchestrator/effort/context/compact/Rules 预算）+ CLI 进阶四招”解释了怎样“爽用”，但因全篇没有作者自己的受控跑分或实测案例产出（5 例全是外网作品），故**不将外网作品或教程命令记为作者亲测实测案例，也不立实测案例卡**。

## 结构推进

个人体验评价与黑五/重置卡态度 → 01. 5 个外网 Neon 3D/粒子案例（其中 2 例附 Opus 5.5 对比） → 02. `agy` 省 Token 四大机制（Orchestrator 双模型交接、`/effort` 分档、`/context` 与 `/compact` 清算、Rules 24KB/20000 Token 预算与 `@filename` 引用技巧） → 03. `agy CLI` 进阶四招（`/usage`、`/codesearch`、`/diff`、`agy -p`） → 结尾“御三家至少用一家”与个人励志寄语。

结构非常实用：**前段用外网视觉作品建立能力上限预期，后两段全篇下沉到“为什么额度掉得快、怎么省、怎么查”的日常工具手册**。

## 失败、限制与不宜照搬处

- 证据身份限制：文章标题与第 01 节虽写“Neon 实测 Case”，但第 01 节 5 个案例全部是外网第三方创作者的展示作品，第 02–03 节主要为 Antigravity 文档与功能解析，作者未提供自己从零跑通的实测案例、失败日志与前后账单，故本篇不纳入实测案例卡。
- 时效与文档边界：黑五 50% 折扣截止 11 月 26 日，过期即失效；24KB / 20000 Token 规则预算、4% 缓存命中提升和 `182.4k → ~31.2k` 等数字均属官方说明或示例口径，需按自己当前实际安装版本核对。
- 不宜照搬处：不得把“500 刀订阅吐槽”“之一/之二/之三”黑话、“生产力超过 99% 竞争者”的暴论和结尾鸡汤直接照抄；本篇单次互动快照为阅读 46618、点赞 53、老赞 192、转发 728、收藏 171、评论 52（同日另篇仅 5207），仅属单次观察窗口，不构成日常基线或传播因果，未测本账号读者效果。

## 可迁移写法与自己的待测方向

- 可迁移动作：写工具省额度教程时，不只泛泛说“清理上下文”，而是把**规则文件引用语法差异（全量内联 vs 仅传路径）、触发模式命名坑（`model_decision` vs 驼峰错写）、闲置 MCP 禁用、不耗 Token 的本地搜索命令**做成可复制的排查清单；写促销好消息时敢于顺带吐槽不合理的营销机制（如重置卡）以立住用户立场。
- **待实操**：面向高频使用编程 Agent CLI 的开发者，在自己的一个脱敏小型代码仓库中建立两套对照配置（A 组：将 10 KB 说明文档用全量内联方式写入根规则并挂 3 个闲置 MCP + 单一高阶模型；B 组：改为路径引用 + 按需 glob 规则 + 禁用闲置 MCP + Orchestrator 规划执行分离）。第一步在同一条跨文件改 Bug 与补单测任务上，分别运行前后执行 `/context` 与 `/usage` 面板截图。观察固定系统开销占比变化、是否触发规则截断、Planner/Executor 交接是否遗漏边界以及实际 Credits/Token 消耗。需保留两套配置文件、任务提示词、`/context` 截图、`/diff` 记录与用量账单，未验证本账号读者效果。
