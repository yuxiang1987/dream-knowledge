# 苍何实测可操控智能体的记忆卡

来源：`raw/article/苍何/最新30篇采集-2026-10-26/一个可操控 WorkBuddy 和 Claude Code 的 AI 记忆卡（强烈安利）-8f158dba-de2398ed59.md`。原题《一个可操控 WorkBuddy 和 Claude Code 的 AI 记忆卡（强烈安利）》，作者：苍何，发布时间：2026-09-27 10:08。[原文链接](https://mp.weixin.qq.com/s?__biz=MzU4NTE1Mjg4MA%3D%3D&mid=2247500450&idx=1&sn=22e00c90d2b79dab57df326f50fbe3b7)。

### 主问题、读者与证据身份
文章要解决的核心问题不是单纯录音，而是如何持续收集手机通知、会议录音、网页收藏和语音输入，使这些材料成为不同 Agent 可调用、可迁移的上下文。目标读者是同时使用 WorkBuddy、Claude Code 等 Agent，且有会议、消息处理、知识管理需求的重度 AI 用户。题材兼具硬件体验、工作流展示和商品推荐。主要证据来自作者自述数月深度使用及若干现场操作；关于阿里无影、连续录音时长、全应用通知采集等能力，仍是作者报告或产品功能陈述，并非本库亲测。

文章的核心判断被概括为：>「AI 要帮我做下一步，得先知道我走过哪几步。」

### 标题兑现、开头与结构
标题承诺一张能操控 WorkBuddy 和 Claude Code 的 AI 记忆卡。正文确实展示了按键触发 WorkBuddy、通过 CLI 连接 Claude Code 等能力，但亲测细节主要集中在 WorkBuddy；Claude Code 只出现在可连接清单和云端类比中，没有同等完整的输入、执行与结果链路。因此标题基本兑现，但两个产品的证据强度不对称。

开头先以“很少如此疯狂、见人就安利”和数月使用建立强烈态度，再迅速点出产品名及 Pro 版本，属于体验背书加产品揭晓式钩子。实际结构依次为：硬件控制 Agent；无影云端 Agent；通知、待办和录音；灯效提醒；Capture、Cliper、ClawPilot Desktop 三款套件；最后上升到上下文所有权。转场多用“如果你以为……”“最牛逼的点”等递进句，从单点功能不断扩展为生态闭环，阅读顺畅，但也强化了销售语气。

### 案例拆解
1. **WorkBuddy 语音操控**：目标是脱离键鼠发起任务；输入为按住卡片后说“讲个笑话”或查询当日知乎前三热榜；操作是连接本地 WorkBuddy，由卡片发指令，复杂案例还要求打开 Mac mini 浏览器；结果据称在屏幕展示笑话或完成查询。正文未提供准确率、耗时和失败次数，人工成本至少包含首次连接、设备常驻及口头确认。
2. **无影 Agentic PC 与小游戏**：目标是在没有 Mac mini 时获得 7×24 小时在线环境；输入为移动场景下的开发需求；结果是作者称在地铁上做出小游戏，并打开云桌面游玩。具体提示词、代码修改、耗时和费用均未给出，属于体验叙述，不能据此判断开发质量。
3. **通知与待办**：目标是避免遗漏会议、还款、取件和被 @ 后的行动；输入是微信、飞书、支付宝等通知流及自定义规则；操作是让 AI 识别事件并生成待办；结果是形成日程。给妻子消息设置红灯提醒是更具体的个人案例，但没有误报、漏报和隐私权限记录。
4. **会议录音知识化**：目标是从会议中提取结论、负责人和待办；输入为最长连续十小时的录音；操作包括转写、定时同步知识库，再在飞书中让 Agent 检索；结果是可询问会议结论。作者需要预先配置定时任务和知识库，转写校对成本未披露。
5. **Cliper 收藏闭环**：输入是浏览超过约 10—15 秒的网页或手动收藏；操作是转成 Markdown、本地保存并由 Skill 扫描；结果是作者在 WorkBuddy 询问刚收藏的网页时获得“准确回复”。这是较完整的亲测链路，但只有单次自有文章案例，没有多网页召回基线。
6. **事件摘要**：ClawPilot Desktop 监听新收藏后自动写摘要，目的是先读摘要、节省上下文；需要人工设置事件，摘要质量和节省比例未量化。Capture 热词与各类 Agent 直连则主要是功能介绍，没有独立结果样本。

### 观点边界、语言与结尾
“开放格式留在本机、换 Agent 仍可带走记忆”支持的是可迁移性价值，不足以证明所有数据绝不外传，也不能证明 Agent 会随时间稳定“更懂你”。原文称：>「Agent 可以换，人生不用从头交代。」

语言高度口语化，频繁使用“太牛逼”“丝滑”“爽感”和排比，负责制造兴奋；视频、截图和界面在文中承担操作证据角色，但材料未提供媒体内容，不能判断其实际展示。结尾从技术回收到“少错过消息”的生活愿望，继而给出“下方入手”入口，商业转化明确。正文没有价格、优惠、佣金或赞助声明，也未明确是否付费购买，合作关系未知。

### 失败、限制与待实操
文章几乎没有呈现失败案例。缺少通知权限边界、敏感信息处理、误触发、转写错误、跨 Agent 兼容失败、续航实测、云端费用及购买价格。作者报告的“10 小时”“10—15 秒”等数字不能视为本库验证。文中也没有同口径阅读、转发或历史基线，不能因“见人就安利”认定爆文或归因传播。

待实操五要素：目标读者为每天处理多群通知和会议的 Agent 用户；自己的输入选一场含明确负责人和截止日的会议录音及一天通知；第一步仅开启本地记录并配置一条被 @ 才生成待办的规则；观察点是转写准确率、待办漏报误报、跨 WorkBuddy 与 Claude Code 的可检索一致性；所需证据包括原始录音、通知清单、生成待办、Agent 查询日志、人工修订时长和网络传输记录。
