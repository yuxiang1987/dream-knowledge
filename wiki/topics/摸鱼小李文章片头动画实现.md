# 摸鱼小李文章片头动画实现

## 已确认的结论

依据本地采集的文章原始 HTML（网页结构代码），这三篇近期文章的片头直接内嵌 SVG（用图形指令描述画面的矢量格式）和 SMIL（在 SVG 内声明动画时序的语法）。片头内存在 `<animate>` 和 `<animateTransform>`，不是通过片头内的图片、视频或 JavaScript 播放画面。此结论只针对所检查片头，不能扩成文章所有媒体或作者全部历史作品。

对本地归档的摸鱼小李文章做结构筛选，找到27个处于正文前、画布为1246×220的同尺寸SVG片头。该数量是本地样本数量，不是账号总作品数量，不代表全部27个都完成了视觉检查。脚本与逐文件字节指纹见 `scripts/analyze_moyu_intro.py` 和 `output/ai-wechat-methodology/moyu-intro-research-20261119/metrics.json`。

三篇近期片头均完成浏览器本地复现，检查了0.5秒、1.8秒、5秒定格；没有操作公众号编辑器，也没有做真机微信验收。

## 固定品牌与文章主题如何衔接

这三篇的构图都使用左侧像素小人、白底、灰绿两色口号。0.5秒定格可见「AI时代的混子，长期摸鱼」；1.8秒定格可见文字退成灰绿方块粒子，主题场景开始出现；5秒定格进入各文章自己的演示。

| 原文样本 | 主题演示内容 | 结构用途 |
| --- | --- | --- |
| Seedream多轮编辑篇（11-13） | 苹果汁主图排字，选框修改字与角标，再将图层展开并合拢 | 将小字生成、多轮编辑、图层分离变成可见动作 |
| Seedance Flash篇（11-14） | 监视器画面配合更快、更便宜、多版本三幕 | 片头预告正文比较维度；画面中的时间、价格只是作者展示信息，不是本次独立核验结果 |
| 豆包多模型篇（11-16） | 游戏机依次插入Kimi、GLM、DeepSeek卡带，换屏并点亮指示灯 | 用换卡带比喻按任务切换模型，先建立理解入口 |

以上完整动作顺序结合片头 `aria-label`（写给辅助阅读工具的说明文字）与时序代码分析；本次没有逐帧视觉验收每个中间动作。

可迁移的设计判断：固定品牌元素负责辨识，变化的主体动画负责解释本篇主题。不能由成品判断作者内部是否真的使用模板或自动生成管线；但复用母版、替换主题场景是我们可采用的实现方案。

## 代码如何实现

以11-16豆包多模型篇为例：片头UTF-8代码147296字节，包含82个path、61个rect、74个animate与73个animateTransform。全部片头动画不依赖外部图片、字体或脚本引用；此处指扫描到的片头自身资源，不包括文章页面其他部分。

| 画面表现 | 源码机制 | 普通话解释 |
| --- | --- | --- |
| 像素人物与文字 | path、rect以及多层g分组 | 把轮廓、像素块画出来，再按部件组合；该片头没有text元素 |
| 文字变粒子 | 字形轮廓与方块的透明度交接，再移动各分组 | 并非必须逐像素模拟真实破碎，视觉上连续的交接也可形成粒子效果 |
| 卡带飞入、抬起和落槽 | animateTransform的translate、rotate、scale | 同时控制位置、角度和缩放，并用嵌套分组叠加 |
| 灯亮、文字换屏、打勾 | animate控制opacity，部分元素另做缩放 | 提前画好不同状态，在指定时间显隐 |
| 快慢变化、落下回弹 | keyTimes、values、calcMode="spline"、keySplines | 定义每个动作何时到哪里，以及途中怎样加速和减速 |
| 循环与人物待机 | repeatCount="indefinite"及不同dur | 主场景以8秒为周期，人物另有2.2秒、3.2秒节奏；整个画面不必每8秒完全同相复位 |

例子：首个场景分组透明度的原值为 `0;0;1;1;0;0`，对应时间 `0;.22;.26;.875;.905;1`，周期8秒。换算后主题场景约1.76秒开始淡入，2.08秒显示，7秒开始淡出，7.24秒隐藏。这里只计算这个场景组，不等于内部所有子元素同时出现。

首张卡带有位移、旋转与缩放三个嵌套动画。机器还在插入节点附近下沉约4个画布单位后回位，指示灯从0放大到1.5再收至1。它的顺滑感来自运动曲线和关联反馈，增加无关特效并不能替代这些动作关系。

## 程序员梦哥可采用的做法

以下为本次设计建议，尚未制作或发布。保留自己的头像、颜色和文案，建立三部分可配置母版：品牌亮相、过渡、主题演示。借鉴动作关系和时序，不把他的人物、口号及代码直接当作本账号资产。

1. 先固定人物、账号名、短口号，控制首屏高度。
2. 将本篇主题压成一个动作隐喻，例如3D课件用「平面图展开成立体装置，点击后运动」，让片头与正文直接相关。
3. 只安排两三个有关联的动作：输入、处理、结果；给关键动作加微小回弹或指示反馈。
4. 用SVG/SMIL实现原版，保留字形与图形的独立分组，以及便于调整的时序参数。浏览器HTML内嵌SVG与独立SVG文件的大小写规范不同；原采集HTML中属性已小写，导出独立XML时须正确恢复大小写并验证。
5. 保留GIF备用输出；具体使用SVG还是GIF需经过公众号后台粘贴、保存重载与手机微信播放检查后决定。现有默认片头不在本次研究中改动。

### 2026-11-25 最新 30 篇（实得 25 篇）深度蒸馏：非卡片布局与高阶物理/粒子技法

通过 TikHub 抓取「摸鱼小李」(`gh_3923025946c5`) 最新 30 篇（其中 5 篇接口返回 HTTP 400，实际分析 25 篇内嵌 SVG，快照与统计保存在 Git 忽略目录 `output/moyu-svg-research-2026-11-25/`），发现其画面丰富度的核心并非卡片模板，而是以下结构与技法：

1. **7 种空间排版范式（近半数无大矩形卡片框）**：
   - **隐喻变形流**：如《百灵健康大模型》望远镜仰望星空→星星落临界线→低头变成听诊器贴家门听心跳；《Hy4 flash 3D 课件》坐标轴草图→小黄点跳落描字→零件拼成火箭冲出画面。
   - **2.5D/3D 空间与图层炸开**：如《Kimi K3.1》Three.js 透视地面网格 + 坐标轴 + `animate:points` 旋转 3D 立方体；《Seedream 5.5》7 层玻璃板 `skewY` 横向炸开再吸合；《RunningHub Blender》立体白模片场双人对打迸火星再缩进胶片。
   - **节点连线管道**：如《亚马逊 AI 创业路演》灯泡→虚线跳 4 节点→地球；《LibTV》对话卡→贝塞尔连线跑光点→场记板拍合吐胶片。
   - **角色表演 + 全幅粒子**：如《STEPX AI DJ 台》音符从耳罩和吉他源源不断飘满整条横幅；《Lovart 2.0》像素小兽快速切帧变形→炸开 10 只排排跳。
   - **单监视器内切幕**（《Seedance 2.5 Flash》）、**左右分屏/对话拼装 UI**（《右键 WorkBuddy》《Intelligent UI》）、**游戏机/咖啡杯吐卡**（《豆包多模型》《咖啡季 5 工具》）。

2. **四大高阶动效技法与黄金缓动分工**：
   - **三段式物理发射**：点火前 `1.6px` 线性微震（`keySplines="0 0 1 1"`）→ 起飞前向后退并轴向挤压蓄力（`scale=".94 1.07"`）→ 拉伸加速冲刺离场（`keySplines="0.55 0 0.85 0.45"`）。
   - **双向线稿描边（`stroke-dashoffset`）**：25 篇共使用 35 次；前半程正向画入坐标轴/星图，后半程反向擦除退场，实现无痕转场。
   - **多段抛物线粒子喷泉**：20+ 独立粒子以 `0.011`–`0.015` 错峰发射，3 点抛物线位移铺满横幅。
   - **主循环时长自适应**：按信息密度选用 `4s`/`5s`/`5.5s`/`6s`/`8s`，左侧像素 IP 始终保持 `2.2s` 呼吸与 `3.2s` 眨眼异步错开。

以上技法已沉淀为 `gzh-svg-intro` 的 `pipeline-nodes`、`viewport-3d`、`split-editor` 模板及 `launch_recoil`、`particle_fountain`、`stagger_bounce`、双向 `smil_stroke_draw` 原语。
