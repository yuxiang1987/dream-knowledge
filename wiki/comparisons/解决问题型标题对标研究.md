# 解决问题型标题对标研究

## 结论先行

**解决问题型能不能用，先看正文有没有「读者问题—可用路径—可指认终点」三件套；有，标题才可以让痛点承担主要期待。** 本批10篇里7篇是解决问题型，阅读÷同号中位数从0.22到2.31，跨度约10倍；邻接样本也有高于中位数的。分类的价值是判断标题和正文是不是同一份合同，不是预测阅读。

与[[comparisons/实践型与教程型标题对标研究]]配套：那份研究回答实践型「围观成果」与教程型「照着得到」怎么取材，本页补第三类「解决一个具体问题」的取材与兑现条件。三份样本合起来22个独立作品（18＋10，无重叠），都来自同一批2026-10-26互动快照。

## 分类口径：标题有问号不等于解决问题型

- **解决问题型**：正文针对一个具体读者问题，给出可用解决路径或判断，并能指认读完后读者能做什么。方案可绑定单一产品，但要标明无对照。
- **邻接样本**：主交付是测评、资讯、故事、产品安利或功能展示，问题只是引子，或标题承诺大于正文可交付。
- 个人故事即使解决了作者自己的问题，没有可复用步骤或判断规则，也算邻接；只有功能巡览与购买引导的也算邻接。

按此口径，10篇中7篇解决问题型（#1、#2、#3、#6、#7、#9、#10），3篇邻接（#4、#5、#8）。

### 1. 爱AI的大刘：把“选择困难”收束成三条差异与一种分工

**原题逐字**：一篇讲清楚 Claude Code 和 Codex，到底选哪个（附实操建议）。

**数据**：阅读 43,701；分享 3,818；收藏 1,451；同号中位数 18,890；倍数 2.313446；分享/阅读 8.74%；收藏/阅读 3.32%。

**来源**：raw `raw/article/爱ai的大刘/tikhub-2026-10-26/一篇讲清楚 Claude Code 和 Codex，到底选哪个（附实操建议）。-531f663e-f7741032bd.md`；source `wiki/sources/大刘选择Claude Code与Codex.md`。

**目标读者**：在 Claude Code 与 Codex 之间纠结的开发者、非程序员和纯小白；尤其适合在“开箱即用”与“自由配置”之间权衡、已有双工具预算的人。

**正文主交付与判定**：解决问题型（选择决策）。正文先解释聊天产品与编程 Agent 的区别，再给三条差异：封号风险、使用逻辑（IDE 终端 vs App 内置）、改文件体验（Codex Review 面板看 diff 但跳出外部编辑器，Claude Code 在终端里就地改），最后把选择收束成“不是二选一，是分工”。读者能带走一套按任务分配工具的判断，而不是安装步骤。标题的“实操建议”更接近长期使用心得，不是可复现实验。

**标题怎么提出痛点/承诺解决/是否给选择依据**：
- `一篇讲清楚`：承诺降低理解成本，一次解决选择困难；`到底选哪个`：直接点名二选一；`附实操建议`：告诉读者不只有观点，还有可执行建议；两个高认知产品名负责搜索与认领。
- 吸引点是“高价值选择 + 一次性讲清”的确定感，不是靠夸张情绪。正文确实给了选择依据，且依据落在日常摩擦（封号、终端配置、改文件）而不是跑分。
- 但标题说“选哪个”，正文终点是“分工”，属于对二选一的部分改写；这既是诚实，也是承诺范围的偏移。

**正文解决路径与兑现位置及终点**：共同点在第11—21段；三个区别在第25—45段（封号25—29、使用逻辑30—37、改文件38—45）；个人分工与总结在第46—51段；token 建议在第53—60段。终点是第51段“不是二选一，是分工”。第53段之后的“每天一亿 token”与选型关联较弱，属于作者方法论外延。

**连续原文锚点**：
> 「像到这个地步，代码能力早就不是选择依据了。」——共同点段末、进入三个区别之前（正文第22段）。

> 「真正想“好用”，二者都有各自的优势，关键看你的需求」——三个区别之后、个人分工之前（正文第46段）。

> 「不是二选一，是分工。」——核心选型结论（正文第51段）。

**限制与不宜照搬**：没有同一代码任务下的质量、速度、token、费用、人工修正对照；没有价格、配额、上下文长度表；封号与 KYC 描述缺官方链接、日期和样本边界；每日三亿/两亿 token 与“5—10倍输出”是作者自报。不能把“一篇讲清楚”当成已有一锤定音答案，也不能把作者的双订阅配置搬成读者预算建议。

**合作披露**：无明确广告/赞助/合作披露；作者自述使用 Claude 20x Max 与 Codex Pro（是否自费未说明），无购买链接、优惠码或返佣说明，单篇合作关系未知。

- 它比纯功能稿强的地方，是痛点先行、案例有前后对比（皮肤/发丝/眼神、角色库、7个分镜、双人站位）；但“第一选择”仍缺同类对照。

**连续原文锚点**：
> 「最近LibTV正好有一套工作流，专治这种问题。」——朋友痛点之后、四个案例之前（正文第6段）。

> 「整个使用的过程就是把原图拖进LibTV画布，调出底部预设里的人像质感调节。」——案例一操作段（正文第14段）。

> 「从剧本到分镜再到视频，一条工作流一个晚上全跑完了。」——案例三结果段（正文第37段）。

**限制与不宜照搬**：单一朋友、单项目、无竞品、无盲评、无失败样本；“能直接当定妆照”“效率翻几倍”是朋友评价；23个预设角色是界面观察；百亿播放、行业使用量、“定义标准”是平台/作者主张，未给信源；图片视频未看，无法复核视觉质量。不能把“第一选择”写成已比较结论，也不能把“一个晚上跑完”当成普遍产能。

## 跨样本归纳：4条有证据的观察，不是传播规律

### 1. 类型不是流量开关：解决问题型内部差异远大于类型之间

7篇解决问题型的倍数从0.221493（#10）到2.313446（#1），横跨约10倍；3篇邻接从0.797058（#8）到1.242039（#4），也不是低值聚集。最高的#1和最低的#10都是解决问题型；邻接的#4、#5都高于中位数。**分类的价值在于判断标题与正文是否签了同一份合同，不在于预测阅读。** 把“解决问题型”当成比“测评型/故事型”更高级的标题类型，本批数据不支持。

### 2. 同号同类型也会天差地别：标题外的因素不能省略

- 大刘同一账号：#1“Claude Code vs Codex 选哪个”2.313446，#10“小白做 skill 难？”0.221493；两篇都是解决问题型、都给了路径，但一篇是广泛工具二选一，一篇是垂直 Skill 制作工具，且#10发布早约1.5个月、演示无实际产物。
- 西羊石同一账号：#3“输入剧本做短剧”1.294058，#7“为什么批量还是选 Fast”0.844644；两篇都给了步骤/判断，但一篇是单产品全流程，一篇是三模型量产对比。
- 这不是“同号对照实验”：题材、发布后龄、模型热度、封面、分发都不同。它只能证明**不能从单篇高低反推某个标题词有效**；要比较标题，必须同正文、同账号、同窗口、可合法随机化。

### 3. 高样本更像“承诺—证据对齐”，低样本更像“承诺强于证据”

- #1 承诺“选哪个”，正文给三条差异和分工；#2 承诺“告别AI脸”，正文给四段可操作案例；#3 承诺“输入剧本做短剧”，正文给六段流程和三档；#6 承诺“提示词和方法论全放出来”，正文真的放了完整 prompt 和五段方法；#9 承诺“开源提示语”，正文真的给了三态提示语。它们的承诺强度与正文可指认的材料大致对齐。
- #8 承诺“告别抽卡/交付级时代”，正文是单模型三轮成功案例，无对照、失败率；#10 承诺“帮你把这件事解决了”，正文是工具流程和一个没有实际产物的演示；#2 的“第一选择”也缺竞品对照，但它靠四段具体操作把“可用路径”补足，所以仍高于中位数。
- #7 是反例：承诺不算夸张（“我还是选 Fast”），正文也有公式和场景，却低于中位数；说明“对齐”是必要感，不是充分条件。题材（量产模型对比）、读者面、发布时点都可能影响。
- 可迁移的判断不是“别夸张”，而是：**标题最强的承诺，必须能在正文找到一个可指认的段落作为终点；找不到就降级为体验/测评标题。**

### 4. “可带走资产”换的可能是分享/收藏，不是阅读

本批出现明显分化：

- #6（提示词+方法论）、#9（开源提示语）、#10（开源工具）阅读/中位数只有0.909593、0.770290、0.221493，但分享/阅读分别10.35%、10.26%、13.74%，远高于#2的0.86%、#3的2.82%、#5的2.09%；#10收藏/阅读4.11%为全组最高，#1为3.32%。
- #2 阅读1.537817但分享/阅读0.86%、收藏/阅读0.15%，说明“高阅读”不等于“高保存/转交”；故事/产品展示可以被看完，但不一定被当作以后要用的资料。
- 这只能提示**不同标题承诺对应不同读者行为**：资产型标题可能被窄受众保存/转发，阅读量不高；故事/痛点型标题可能阅读高但收藏低。不能把分享数直接当“内容质量”，也不能把阅读低直接判标题失败；分享也可能来自社群、作者转发或抽奖，快照没有拆分来源。

## 标题吸引点与已验证效果必须分开

### 标题吸引点（语义解释层，有原文支撑）

本批标题主要用了五类装置：

1. **二选一/选择依据**：#1“到底选哪个”、#7“为什么我还是选”。吸引点是高价值决策 + 反共识，读者想知道“我该选谁/为什么”。
2. **告别某痛点**：#2“告别千篇一律的AI脸”、#6“怎么少抽卡”、#8“告别抽卡”。吸引点是把一个反复发生的具体痛苦说成可以被结束的状态。
3. **具体对象 + 能力**：#4“可操控 WorkBuddy 和 Claude Code 的 AI 记忆卡”、#5“胡楚靓……帮我解决了爸妈的旅行”。吸引点是画面感、名人/家庭故事、对象新奇。
4. **可带走资产**：#6“提示词和方法论全放出来了”、#9“开源「红绿灯」提示语”、#10“我开源的这个工具”。吸引点是“不是听道理，是拿到配方/工具”。
5. **身份 + 问句**：#3“AI制作到底能有多省事？”、#10“小白做优秀 skill 难？”。吸引点是让读者认领身份/任务，再用问句制造“我是不是也有这个问题”的代入。

### 已验证效果（数据层，能说什么）

- 已验证：原题、账号、ID、阅读/分享/收藏、同号中位数、倍数、raw 路径、source 路径、锚点连续存在、正文主交付与分类判断。
- 未验证：标题导致阅读/分享/收藏；点击率；封面/推送/分发贡献；产品能力、价格、性能、画面质量；作者实际工时；合作/付款关系；读者是否照做；长期效果。
- 因此本文只能说“这批样本里，某标题装置同时出现在高/低样本”，不能说“该装置有效/无效”。真正要验证，需要同正文多标题、同账号、同时间窗、可合法随机化的对照，并同时记录阅读、分享、收藏、发布后龄与分发位置。

## 后续标题技能建议：取材顺序（本轮不改 Skill）

建议把“解决问题型标题”做成一个**取证 → 分流 → 拟题 → 自检**的流程，而不是一组固定句式：

1. **先取正文的“问题—路径—终点”三列表**：读者问题是什么、正文给了哪几步/哪条判断、读完后读者能做什么。三列缺一列，就不要写“解决/告别/一篇讲清楚”。这一步决定能不能进解决问题型；只有测评结论→体验/实测标题；只有故事→“我怎么……”标题；只有功能→“我用X……”标题。
2. **再取读者问题的原话/场景**：优先用开头、评论区、读者来信里的原话，而不是作者自造的大词。标题前半句优先放具体对象/场景（#2“AI脸”、#3“输入剧本”、#4“记忆卡”、#5“爸妈的旅行”），让读者先认领。
3. **再取选择依据/对照**：正文有两项以上选项 + 明确标准，才用“选哪个/为什么选/第一选择”；单一产品工作流可以写“怎么做/我用它怎么做”，不要写“第一选择”。#1有封号/使用逻辑/改文件三条依据，#7有三模型+价格公式，#3只有单产品三档，所以#3更适合“输入剧本→短剧”的结果型，而不是“第一选择”。
4. **再取可带走资产**：只有完整给出提示词/模板/清单/安装方式，才用“全放出来了/开源/附”。#6/#9确实给了，#10给了安装与流程但没给实际产物；标题可以写“开源工具/安装方式”，不宜写“保证优秀”。
5. **再取具体对象/热点/作者身份**：产品名、模型名、名人、作者身份能帮助搜索和认领，但不能替代前三项。#7把H3/Wan放前面，可能吸来新品资讯读者，而正文是量产选择；#5把胡楚靓放前面，吸来故事读者，而正文不是教程。热点名可以放，但要和正文任务对齐。
6. **最后才加情绪钩子，且只加一个**：告别/第一选择/强烈安利/问号/“一篇讲清楚”。钩子必须挂在第1步找到的终点上；不要同时叠加“告别+第一选择+强烈安利+问号”。#2的“告别AI脸”能成立，是因为正文四段都在处理这张脸；#8的“告别抽卡”弱，是因为正文只证明单模型能出好图，没有证明抽卡被消除。
7. **做标题—正文合同自检**：标题每个承诺，标出正文兑现段落；找不到就删承诺或降级标题。再检查“终点是否可指认”：是“选谁/怎么分工”“走完哪条流程”“拿到哪个资产”“判断什么”，而不是“变强/起飞/封神”。
8. **评估时分开看阅读、分享、收藏**：同号中位数只做阅读基线；分享/阅读、收藏/阅读单独记录；发布后龄、推送位置、封面、题材都记。不要用阅读单一指标判标题，也不要把分享高直接当内容好。

**一句话的取材优先级**：正文可交付终点 > 读者问题原话/场景 > 选择依据/对照 > 可带走资产 > 具体对象/热点/身份 > 情绪钩子。先有证据，再选钩子；不是先选“爆款词”，再让正文去凑。

## 待验证假设（本轮未执行）

- **H1，类型效应假设**：在相同正文、相同账号、相同时间窗下，解决问题型标题是否比体验/测评型标题带来更高阅读？本批7篇解决问题型从0.221493到2.313446，无法回答；需要同正文多标题的合法对照，并记录点击/阅读/分享/收藏。
- **H2，选择型标题的适用条件**：`二选一/为什么我还是选` 可能只在“读者正面临该选择 + 正文给同等对照”时有效。#1高、#7低提示读者面与题材可能是调节变量；需要同正文比较“选择型”与“结果型”标题，并分层看读者是否已有该选择。
- **H3，资产型标题的分享/收藏效应**：`提示词/方法论/开源/工具` 可能提高分享与收藏、但不提高阅读（本批#6/#9/#10的分享/阅读10.35%/10.26%/13.74%，#10收藏/阅读4.11%）。需要同正文标题变体，分别记录阅读、分享、收藏、实际领取/安装，不能只用阅读。
- **H4，告别型承诺的兑现条件**：`告别X` 可能只在X高频、可感知、正文能量化或至少给出可验收终点时有效。#2高、#8低、#6接近中位数，提示“告别”不是充分条件；需要控制X的具体性与正文证据强度。
- **H5，问号与第一人称的作用**：#3问号高、#7问号低、#10问号最低；#7第一人称“我还是选”低。样本不足以判断问号/第一人称本身，需要同正文对照，并区分“真问题”与“修辞问号”。
- **H6，发布后龄与分发混淆**：本批#10发布最早（2026-05-21）却最低，#9最新（2026-10-13）也低于中位数；不能用“老文累积久”解释高低，也不能用“新文没曝光”解释。需要精确记录发布时刻、快照时刻、推送位置、转载与社群分发，才能把标题效应从分发效应里拆出来。
