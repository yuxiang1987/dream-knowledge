# 我用GPT Image 2.6 手搓了一套鲁班皮肤

不知道诸位对游戏有没有一种情怀或者执念。

我平时喜欢玩《王者荣耀》，最喜欢的英雄就是**鲁班七号**。虽然菜，但是总想给他安排一套好看的皮肤，奈何口袋比脸还干净。

这几天，我就一直在琢磨，自己能不能用AI手搓一套鲁班的皮肤。虽然不能在游戏里用，当个心理安慰也好啊。

正好，上周OpenAI官宣，自己的**生图模型叒叒叒更新了！**

那就先用GPT Image 2.6试试。从皮肤造型开始，再给它配上攻击特效和表情包，看看这一套能做到什么程度。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/file-20261113210315249.png]]

先简单说说这次更新。

按照OpenAI的说法，Image 2.6的图像生成速度比以前快了50%。API里有Flare和Sunburst两个版本，前者偏向快速生成和迭代，后者更侧重细节，以及多轮编辑时的一致性。Flare在低画质下最快六秒出图，不过这个数字有前提，不能直接当成每次生成的等待时间。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/file-20261113210535947.png]]

更让我想试试的是，这次还增加了GIF功能，可以让静态图片动起来。

![](https://mmbiz.qpic.cn/mmbiz_gif/dCG7OC48IfKVoAzkS5aegCFv8OTtHKeM7JicsicYkvGsc8OpXjkMM6ws1cNv8ruRc5rfLpytyykdbwoshQwLvvq1ngoA57tVl2P4SXrKUxPxA/640?wx_fmt=gif&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=3)

鲁班的皮肤正好适合拿来试。立绘好看是一回事，拿起武器、放出技能以后还像不像同一套设计，又是另一回事。

说干就干。

## 先给鲁班七号挑一套新衣服

我先让Codex调研鲁班现有的皮肤，再根据动漫、机甲、电影这些方向，给我几套创意方案。

```prompt
你帮我调研一下王者荣耀这款游戏，我想给鲁班七号这个英雄创造一款皮肤。你先调研它现有的皮肤，然后可以根据动漫角色、机甲、电影等主题来进行设计。你先给我3套有创意性的方案，先不要生成图片。
```

它给出的三套方案分别是**醒狮机甲、电玩外骨骼、太空维修班**。我又让它生成预览图，先看看长什么样。

先说生成时间，我主观上没有感受到特别明显的提升。这次没有做严格计时对照，速度就不下结论了。

图的效果还是一如既往地好，只是我觉得，跟原版太相近了。画得精致归精致，但我想要一套更有新鲜感的造型。

这时突然想起DeepSeek那条大肥鱼。不如做一款海洋主题的，后面还可以跟大肥鱼炒个CP。

```prompt
你调研一下最近很火的DeepSeek大肥鱼，以海洋为主题，创造一款皮肤。鲸鱼帽、透明水舱背包、泡泡鲸鱼武器，整体更轻盈可爱。
```

我还上传了一张大肥鱼的图片作为参考。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/file-20261113221341929.png]]

接下来看看效果。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/file-20261113221404779.png]]

哎，还真是我想要的样子。

头顶是一只鲸鱼帽，背后背着透明水舱，手里的武器也变成了鲸鱼造型。连那种有点欠揍的坏笑，都给留住了。

这张图可以多看几个细节。帽子上的喷水、胸前的水滴挂饰，还有鞋子两侧的鱼鳍，都在往同一个海洋主题上靠。透明部分能看到水和气泡，武器、背包也用了相近的蓝白配色。

这些地方放在一起，比单独换一顶帽子更像一整套皮肤。右侧还给出了武器、局部细节和背面造型，不用只靠正面图去猜背包长什么样。

接下来，我让它把鲁班和大肥鱼放进同一张图里，看看换了姿势、加了另一个角色以后，形象还能不能接得上。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/file-20261113221656111.png]]

鲸鱼帽、棕色头发、蓝白衣服和手里的武器都还在，主要特征没有丢。大肥鱼原来的参考图是半身照，这次也补出了全身，两个角色放在一起，画风看着挺协调。

当然，姿势和局部细节会有变化，不能说每个地方都和原图完全一样。但作为这套皮肤的合照，我觉得没什么违和感。

## 只改帽子颜色，其他地方别动

造型有了，我又补了一次局部修改。

这次要求很简单，只把左侧主角色鲸鱼帽的蓝色外壳改成珊瑚橙。人物的脸、衣服、武器都保留，右边那些小图也别跟着变。

```prompt
在我上传的原图上做一次局部修改。
只把左侧主角色头上鲸鱼帽的蓝色外壳改成珊瑚橙色，保留原来的材质、光泽和明暗层次。帽子的白色部分、眼睛、形状、大小，以及旁边的耳机都保持原样。
人物的脸、表情、头发、姿势、衣服、背包、武器和鞋子保持原样。背景、文字、构图，以及右侧所有细节展示图也保持原样。
直接输出修改后的完整图片。
```

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/鲁班鲸鱼帽局部改色结果.png]]

从结果看，左侧主角色的帽子外壳换成了橙色，白色帽沿和旁边的蓝色耳机还保留着。右边帽子细节图、背面图里的帽子仍然是蓝色，没有一起换色。

这一点正好对应了这次的要求。我让它改的是左边的主角色，并没有让整张设定图统一更新配色。

武器、水舱背包和蓝白衣服，也没有跟着变成橙色。整体看，修改集中在指定的帽子区域。不过截图只能支持这个范围的观察，细小纹理有没有变化，还得把原图和修改图放大对照，不能直接说其他像素一点没动。

这次界面显示用时4分钟，也谈不上秒出。对这种已经有满意底稿、只想换一个局部的需求，能保住主要设计，比重新抽一张完全不同的图更有用。

## 皮肤主题定了，让鲁班动起来

接下来做攻击动效。

我让Codex先调研鲁班七号的技能，再围绕这套大鱼皮肤，把三个主动技能和一个被动技能的攻击特效做出来。

```prompt
你调研一下鲁班七号的技能，应该是三个技能一个被动，然后生成相应的攻击特效动图。
```

这是最后的效果。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/鲁班大鱼四技能.gif]]

被动「火力压制」、一技能「河豚手雷」、二技能「无敌鲨嘴炮」和大招「空中支援」，四种效果都做了出来。

被动和二技能沿用了武器里的水和泡泡元素，一技能把扔出去的手雷换成了小鲸鱼，大招则让鲸鱼飞到上方，再往下落水弹。

我感觉，是不是比电玩小子的皮肤还要好看一点。当然，这纯属个人偏好。

这组效果有意思的地方，是静态图里的设计被接着用到了动作里。武器原本就像一个装着水的鲸鱼炮，发射水弹和泡泡，视觉上比较顺；大招继续用鲸鱼，也能和帽子、背包呼应。

如果四个技能只是分别套上不同颜色的光效，和前面那套海洋造型的联系就弱了。现在至少从主题上看，能认出来它们属于同一套设计。

不过，这里展示的是同人皮肤的攻击特效概念。游戏里的命中、伤害和技能判定，并没有在这里实现，也不能把这几秒的动图当成已经做好的游戏皮肤。

有了武器和动效，我又想看看，这个鲸鱼炮如果分成零件，会长什么样。

```prompt
帮我生成cad机械拆解图
```

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/file-20261113223104137.png]]

它把外壳、水舱、握把、鱼鳍等部件分开摆了出来，再用编号和右侧部件表对应起来。上壳、下壳的位置也能看明白，右下角还放了一张组装后的完整武器，方便来回对照。

这张图的中文标注看起来比较清楚，没有明显的乱码。比起只有一堆线条，编号和部件名称让人更容易看懂它想表达的结构。

但它目前仍然是一张概念结构示意图。没有尺寸和装配验证，不能拿着就去制造鲸鱼炮。放在这次皮肤设计里，它更适合补充道具设定，看看角色手里那把武器还能怎样展开。

## 趁热打铁，再做一套表情包

不知道你的表情包里有没有鲁班七号，反正我是没有。

所以我又顺手让它做了12张表情包。原本想做喜怒哀乐，结果它建议，单纯的情绪太普通，不如围绕玩家打游戏时的动作和反应来做。

真的太懂我了。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/file-20261113223506881.png]]

它先给了12种情境和配文，再做出一张整体效果图，让我看看有没有需要修改的地方。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/file-20261113223606778.png]]

开局时扛着鲸鱼炮，一脸自信地说「这把看我的」；被抓了以后，缩成一团说「怎么又是我」；残血逃走，抱着武器来一句「还好我跑得快」。

单看「开心」「难过」「生气」，还得想想用在哪。这几句跟游戏里的情境放在一起，光看动作和配文，就能明白它在表达什么。

里面也不全是得意的表情。「失误失误」「保护一下我」「这怎么玩啊」，和鲁班这个角色放在一起，反而挺有喜感。

原来的鲸鱼帽、耳机和蓝白衣服也都接着用了。角色有的站着，有的抱膝，有的躺下睡觉，表情和姿势比立绘夸张，但主要造型还能认出来。

整体我觉得不错，就让它继续生成了动图。

![[assets/我用GPT Image 2.6 手搓了一套鲁班皮肤/十二张动图预览.gif]]

这里展示的是12张表情的整体动态预览。真要当聊天表情用，还要看单张导出以后，在手机上能不能看清文字，动作会不会太小，以及添加和发送是否正常。这一步还没测，就先不说已经实现表情包自由了。

## 写在最后

最开始只是想给鲁班换套新衣服，最后从角色设定，做到了合照、局部改色、攻击动效和表情包。

这次让我觉得有意思的，是同一张满意的角色图还能继续往下用。鲸鱼帽和水舱定下来以后，武器、技能和表情都有了可以沿用的元素，每一步都能接住前面的设计。

当然，图里好看，跟在游戏里能用，还有很长一段距离。局部修改也需要对照原图，表情包还得拿到手机里看实际效果。

但如果你也有一个喜欢的角色，或者想给自己的头像、吉祥物做一套配套素材，这样从一张图慢慢往外扩，倒是个挺有意思的玩法。

至于我这套鲁班皮肤，虽然暂时穿不进峡谷，至少想要什么样的鲸鱼帽、拿什么样的武器，现在可以自己安排了。
