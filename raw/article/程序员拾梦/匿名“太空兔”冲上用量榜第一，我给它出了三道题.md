这两天，AI圈都在猜一只兔子的身份。

Space Bunny，中文叫「太空兔」。它已经连续五天登上了 OpenCode 用量榜第一。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/BBnmXtwleolbzkmTkuGj1WoGhEVXMJibRsjp0Wpp2yAEJHuwpVzTsrVqREY3e0tQIia7pb2ZJk40cCqg7BKev2jYIX9QmrOnVUtoZbEmndEbY/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=0)

免费、百万上下文、支持图片和视频输入，听起来很诱人。

但名字没听过，厂商也没公开，大家的好奇心倒是先被拉满了。

有人从兔子联想到月之暗面，也有人根据分词特征猜 MiniMax。官方身份还没确认，猜谜已经成了另一场比赛。  
![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/BBnmXtwleonkmxic5W5AEVtgMpTF1VTzMFNwicqUUDNIO30eLErLBHysiaOpGnbTwrAseZM2ibKa7dv8jsD0JgzmR2QVraBDCyBZRAIQ26kcxDg/640?wx_fmt=png&from=appmsg&watermark=1#imgIndex=1)

但相比于网友的好奇心，我更想知道，这只兔子到底能干多少活？

所以今天，我给它出了三道题。

看着铅笔草图，给自己造一座能开车探索的月球基地，做一个下滑时景点丝滑切换的北京十一旅游网页，再写一个落沙沙盒，看看沙、水和酸液能不能按规则运动。

先看它做得漂不漂亮，会不会露馅。

## ✧ 我让太空兔给自己造个家

既然它叫「太空兔」，我就让它在月球上给自己造个家。这题想看看，它能不能读懂草图，再用代码把图里的东西做出来。

我先给了它一张铅笔风格的月球基地草图。兔子造型的主基地、太阳能阵列、温室、着陆区、巡视车停放区、陨石坑，位置和道路关系都画在了图里。

草图也只给了它轮廓和布局，建筑高度、材质和灯光这些，留给它自由发挥。  
![图片](https://mmbiz.qpic.cn/mmbiz_png/BBnmXtwleolblfFiaicjmBAeEcF0JYqQbUL9tPLQp0nNJbTwMOSZoMG6IFWBXAmntouZIrw2L0oHZu1qLWQSmdRNrG1LaWiaGJoCoNeA0icYUKo/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=4)

我让它用 Three.js 把草图立体化。除了旋转镜头看全景，还得能用键盘驾驶巡视车，到月面上逛一圈。

这是我的提示词。

## ✧ 从月球回到北京

现在正好十一假期，我就让它做了一个北京景点的宣传页。这一题主要看它做出的页面呈现和动效，换个角度看看它的编码能力。

我想用长城、故宫、天坛和胡同作大幅背景。下滑时，景点平滑切换，图片缓慢缩放，文字渐入渐出，有一边滑动、一边走进北京的感觉。

这是我的提示词。

提示词

```
在当前工作空间下创建一个bj-travel的文件夹，所有的素材都放到这个文件夹下面
```
```
制作一个“十一游北京”景点宣传长网页，交付完整源码、启动命令和可运行预览。
```
```
重点是滚动叙事：以长城、故宫、天坛、北京胡同的真实照片为全屏背景，下滑时平滑切换景点，配合轻微视差、图片缓慢缩放、文字渐入渐出。桌面端可固定背景并随滚动推进，整体像精致的旅游宣传片，避免生硬跳切和普通卡片堆叠。
```
```
首屏标题“这个十一，走进北京”，随后每个景点一段简短介绍，结尾展示景点入口。提供顶部导航、当前章节指示、点击跳转、景点详情弹窗和返回顶部；所有按钮真实可用。
```
```
使用有授权的清晰照片，注明来源，加载失败有替代显示。文字与背景保持清晰对比，采用有北京文化气息的配色和留白。适配手机，滚动流畅，不强制接管滚轮；减少动态效果模式下保留正常阅读。
```
```
不要编造票价、开放时间或预约政策。完成后实际检查滚动切换、导航、弹窗、图片加载和手机布局，修复问题，说明未验证项。
```

## ✧ 落沙物理沙盒

前两题偏视觉，第三题换成落沙物理沙盒。沙子、水和酸液的规则更具体，也更容易看出哪里不对。

这是我的提示词。

提示词

```
在当前工作空间下创建一个shahe的文件夹，所有的素材都放到这个文件夹下面
```
```
制作一个可在浏览器运行的“落沙物理沙盒”，用原生 HTML/CSS/JavaScript 实现，交付单个 HTML 文件，零外部依赖。
```
```
画面采用深色背景，沙、水、酸液和墙有清晰不同的颜色，界面简洁精致。鼠标或触摸连续拖动即可绘制材料，提供材料选择、橡皮擦、画笔大小、模拟速度、暂停/继续、单步运行和清空按钮，显示当前材料及操作说明。
```
```
必须遵守以下规则：
```
```
1. 沙子每个模拟步最多下降一格；下方受阻时，可向左下或右下空格滑落，堆积后稳定。
```
```
2. 水向下流动，受阻时向两侧扩散；左右条件相同时随机选择，避免固定偏向一侧。
```
```
3. 沙子遇水时交换位置，沙下沉、水被顶起，不能重叠或瞬移。
```
```
4. 墙固定不动，阻挡沙和水。
```
```
5. 酸液像水一样流动；接触上下左右相邻的沙子或墙时，每步最多溶解一个目标，并同时消耗自身；不溶解水。
```
```
6. 所有材料不越出边界，每个粒子每步最多更新一次；模拟速度不应随屏幕帧率明显变化。
```
```
暂停时仍可绘制，单步按钮只推进一个模拟步。适配桌面和手机，触摸画布时避免页面跟着滚动。
```
```
完成后实际检查：沙堆形成、水遇墙分流、沙入水下沉、酸液溶解、暂停绘制和单步运行，以及全部按钮。修复发现的问题，简短说明已验证项与未验证项；没有浏览器工具时如实说明。
```

在画布上用鼠标撒沙、倒水、画墙，再加点酸液，看看这些材料碰到一起会怎么运动。

这一题，确实让我有点惊艳。

沙子、水、酸液、墙和橡皮擦都做出来了，但更吸引我的是它们动起来的感觉。

我往下撒沙，沙子会逐渐堆起来。如果沙子碰到斜面，颗粒顺着障碍往低处滑，连续流下来的过程很丝滑。

水被墙挡住后，也会沿着空隙往低处流。再往水里加沙，沙子能沉到水下，形成不同的层次。

鼠标随手画一道障碍，就能继续观察材料怎么绕过去、落下来，很容易玩着玩着忘了自己是在测模型，呵呵。

酸液的表现也有意思。

墙被腐蚀出缺口后，原来被挡住的材料就接着往下落，看着很自然。

不过，继续玩也发现了两个问题。

大量添加沙子时，画面里会出现像水一样的蓝色颗粒落下来。具体是材料混入还是显示问题，这次没有继续排查。

酸液还把最下面那条看着像装饰框的边线也腐蚀掉了。至少从我的预期来看，这里的边界保护还需要调整。

这两处我没有再让它修改。因为当前版本的整体运动效果已经让我很满意。

虽然还有些细节没做好，但这个沙盒已经让我愿意继续玩下去了。

## ✧ 最后

三道题做下来，我愿意继续用这只兔子。

月球基地改一轮就能上手玩，北京网页没再追加修改，落沙沙盒虽然还有两个问题，动起来的效果确实让我惊喜。

再加上目前免费，我有点理解它为什么这么受欢迎了。
